# S1: Both switchers simplified

Repo root: `/Users/dominykasgrubys/code/trackpad-launcher/.claude/worktrees/013-simplify-switchers` (a git worktree; use absolute paths). Do not commit; the orchestrator commits.

## Goal

The app switcher shows icons and the highlight only, with 22 pt of padding on every side measured to the highlight; the window switcher is 360 pt wide whatever its titles, each title on one line cut short with an ellipsis. Every size that places either panel, its rows, highlight, icons and title column comes from its pure layout value in `LauncherCore` (`SwitcherRowLayout`, `WindowColumnLayout`), and those layouts' tests prove the new geometry.

## Requirements

- **R1. The switcher shows no app name.** The switcher MUST show only the icons and the highlight. It MUST NOT show the name of the selected app or of any other app.
- **R2. The switcher's selected icon stays larger.** The selected icon MUST be drawn larger than the others, unchanged from today, and it MUST stay inside the highlight.
- **R3. The switcher's padding is equal on all sides.** The icon row MUST sit 22 pt from the panel's top, bottom, left and right edges at full size, measured to the highlight's edge, so the highlight on the first icon is 22 pt from the left edge and on the last icon 22 pt from the right edge. At full size the panel MUST be 22 pt + the highlight's height + 22 pt tall. On a display too narrow for the row at full size (icons and gaps shrink by one factor), the gaps above, below, left and right of the highlight are still equal to one another.
- **R4. The window switcher is always 360 pt wide.** The window switcher panel MUST be 360 pt wide at full size, whatever the length of its titles. When the column shrinks to fit the display, the width MUST shrink by the same factor as the rows, and titles are cut short against that narrower width.
- **R5. Titles that do not fit are cut short at the end.** A title wider than the space left beside the preview MUST show on one line, cut short at the end with an ellipsis. It MUST NOT wrap, overlap the preview or reach past the panel's padding. A minimised window's cut title keeps the "Minimised" badge below it; without Screen Recording (app icon in the slot) the panel is still 360 pt wide and the title cut the same way.

Non-goals (do not change): window titles' text; icon size (80), highlight size (92), its motion, haptics, where either panel appears; the window switcher's previews, row height, badge, highlight and padding; the panels' corner radii (34 / 24), glass styles, the 0.12 s transform animation and the spring.

## Design

No port, no model type and no event changes. `Switcher.selectedApp` stays (the model and behavioural tests use it); only the shell stops reading its name.

### `LauncherKit/Sources/LauncherCore/SwitcherRowLayout.swift`

- `padding` becomes **22** and means the gap between the panel's edge and the highlight's edge, on all four sides, constant at every scale (it does not shrink with the row).
- New static `selectedIconScale = 1.12` (moved from `SwitcherPanel.selectedScale`).
- Span the row needs, at full size: `Double(max(iconCount − 1, 0)) × (fullIconSide + fullIconGap) + fullHighlightSide` (positive for any count, so the old `full > 0` guard is no longer needed for that reason; keep the not-positive-display rule).
- `scale = min(1, (displayWidth − 2 × padding) / span)` when `displayWidth > 0`, else 1.
- `panelSize: (width: Double, height: Double)` = `(2 × padding + span × scale, 2 × padding + highlightSide)`. Replaces `panelWidth`; remove `rowWidth` too (nothing outside reads it).
- `centreX(at:)` signature unchanged; becomes `padding + highlightSide / 2 + position × pitch`.
- New `centreY: Double` = half the panel's height (`panelSize.height / 2`).
- Interface after the change: `init(iconCount:displayWidth:)`, `iconCount`, `scale`, `iconSide`, `iconGap`, `pitch`, `highlightSide`, `panelSize`, `centreX(at:)`, `centreY`, statics `fullIconSide` (80), `fullIconGap` (20), `fullHighlightSide` (92), `padding` (22), `selectedIconScale` (1.12). Update the doc comment.
- Full-size footprint is unchanged from today: 5 icons → 536 pt wide, first centre 68, pitch 100. Height becomes 136 (was 160).

### `LauncherKit/Sources/LauncherUI/SwitcherPanel.swift`

- Remove the name label (`name` NSTextField and all its setup), `topPadding`, `bottomPadding`, `nameHeight`, `nameGap`, and `static let selectedScale`.
- Frame: `layout.panelSize` centred on the screen rect (as the width is today).
- Highlight: size `highlightSide` square; origin `x = centreX(at: position) − highlightSide / 2`, `y = centreY − highlightSide / 2`.
- Each icon layer's position `(centreX(at: index), centreY)`.
- The selected-icon transform reads `SwitcherRowLayout.selectedIconScale` (convert to CGFloat).
- `show(position:selected:animatesSize:)` loses its `name` parameter. Update the type doc comment (no more "selected app's name").
- Keep corner radii 34 and 24, glass style, 0.12 s duration, spring untouched.

### `LauncherKit/Sources/LauncherUI/SwitcherPresenter.swift`

- `render` stops passing `name:` to `panel.show`.

### `LauncherKit/Sources/LauncherCore/WindowColumnLayout.swift`

- New `public static let fullPanelWidth = 360.0`.
- Remove `minTitleWidth`, `maxTitleWidth`, the private `fullTitleWidth` stored property and the `widestTitle` init parameter: `init(rowCount:displayHeight:)`.
- Full-size title column derived: `fullPanelWidth − 2 × panelPadding − 2 × rowInset − previewWidth − titleGap` = 360 − 16 − 12 − 120 − 12 = **200**. `titleWidth = 200 × scale` (derived, not a literal 200).
- `panelSize.width = fullPanelWidth × scale`; height unchanged.
- `titleLeading`, slot, row height, padding, fonts and preview sizes unchanged. The title column ends exactly at the row's inset (138 + 200 = 338 = 344 − 6) at every scale. Update doc comments.

### `LauncherKit/Sources/LauncherUI/WindowSwitcherPanel.swift` and `WindowSwitcherPresenter.swift`

- Remove `WindowSwitcherPanel.widestTitle(_:)` (text is no longer measured). `titleFont` stays (the row fill uses it).
- Every `WindowColumnLayout(rowCount:widestTitle:displayHeight:)` call becomes `WindowColumnLayout(rowCount:displayHeight:)`; the presenter builds the layout from `rows.count` and the visible frame's height alone.
- Keep the row view's `title.lineBreakMode = .byTruncatingTail` and `title.maximumNumberOfLines = 1` (around line 150). The window row's own small text and badge insets stay as they are.

## Rules that apply

- `docs/architecture.md` › Shape: "`LauncherCore` (domain types, pure policy, ports, the model; imports Foundation and Observation only)". The layouts stay pure Foundation values; no AppKit/CoreGraphics types (no `CGFloat`) in `LauncherCore`.
- `docs/architecture.md` › Shape: "Policy lives in pure functions and value types; the shell stays thin." Every placing size lives in the layout; the panels only read it.
- `docs/architecture.md` › Language: "Tests use Swift Testing."
- `docs/architecture.md` › Concurrency: "No timers, no polling, no background loops" and "Animation is Core Animation keyframes … display links are banned along with timers."
- `docs/architecture.md` › Privacy: "no logging of any kind (`print`, `NSLog`, `os_log`, `Logger`)". A source-scan test enforces banned APIs.
- Plan: no test outside `SwitcherRowLayoutTests.swift` and `WindowColumnLayoutTests.swift` changes.

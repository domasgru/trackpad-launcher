# S3: The card and the hand-written updater go

## Goal

The settings window shows nothing about updates, the app makes no network request, and *Quit Trackpad Launcher* and every other quit answer with no update guard. `Updater`, the `InstalledRelease` gate and the whole hand-written check, download and install go; what the move to /Applications shares stays. This slice is a deletion. The app is left with no update path on purpose: a later slice builds a new, smaller `Updater` on Sparkle, and nothing here ships before the last slice.

## Requirements

- R15: "The settings window MUST show no update card, no update setting and no update status. Nothing takes the card's place."
- R13, the removal of the install guard: "*Quit Trackpad Launcher* MUST stop the app at once, in any update state... Every other way to quit MUST keep closing only the settings window."
- R14, the removal of the install guard: "Logging out, restarting and shutting down MUST end the app without asking and with no delay from an update."

**Changes because `Release` goes.** `CodeSignature.isGenuine` stays, against a new internal type in `CodeSignature.swift`:

```swift
/// The offer, from the feed, that the extracted bundle's sealed Info.plist must equal.
struct ExpectedUpdate: Sendable { let version, build, minimumMacOS: String }

static func isGenuine(_ bundle: URL, as expected: ExpectedUpdate, signer: Signer) -> Bool
```

Its signature checks are unchanged. Its last step reads `CFBundleShortVersionString`, `CFBundleVersion` and `LSMinimumSystemVersion` from the sealed plist as strings and requires all three to equal `expected`; a missing one is false. Update `CodeSignatureTests` to match. The fixture's `CFBundleVersion` is `1` (see `Scripts/make-update-fixtures.sh`). Its version and minimum come from `fixture.json`. Keep `UpdateFixtures` and `make-update-fixtures.sh`.

## Rules that apply

- `docs/architecture.md`, Shape: "Every port has exactly two adapters: the real one in `LauncherPlatform` and an in-memory one in the tests." So a removed port takes both adapters with it.

The layout otherwise stays exactly as it is.
- `docs/domain-model.md`, Quit Trackpad Launcher: "at once, with no confirmation". The button is never disabled.
- Comments state what is, with no history of what was removed. Do not leave "removed" notes.
- Do not commit: the orchestrator commits your work.
- Worktree guard: write each Bash command with literal arguments, no shell variables, `$(…)` or loops; create and edit files with Write and Edit; absolute paths.

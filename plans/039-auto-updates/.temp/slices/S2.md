# S2: The card's rules outlive the card

## Goal

A new library, `CardContract`, and a new tool, `card-contract`, hold a frozen copy of what every shipped update card demands of a release, with its tests beside them, and `Scripts/release.sh` runs the tool on the stapled archive. The shipped card code stays exactly where it is until the next slice deletes it: this slice copies, it removes nothing from `LauncherCore` or `LauncherPlatform`.

## Requirements

R16 (in part): "Every new release MUST stay installable from the update card of versions before the first automatic-update version. This binds every future release's assets for as long as such copies may exist."

## Design

The update card of every shipped version accepts a release only under rules that live in code about to be deleted. Those rules must keep running on every future release, and must not move when the app's code moves. So they are copied into a target that never ships. **The duplication is the point**: a frozen duplicate of `isGenuine` looks like a DRY violation and is deliberate.

### Targets, in `LauncherKit/Package.swift`

```swift
.target(name: "CardContract"),                                              // no dependencies
.executableTarget(name: "card-contract", dependencies: ["CardContract"]),
.testTarget(name: "CardContractTests", dependencies: ["CardContract", "card-contract"]),
```

No new library product. `project.yml` does not change and does not link them. `CardContract` imports neither `LauncherCore` nor `LauncherPlatform`.

### Files

- `LauncherKit/Sources/CardContract/Version.swift`: the whole of `Sources/LauncherCore/Version.swift`, body unchanged.
- `LauncherKit/Sources/CardContract/CardContract.swift`: every other moved rule, in this one file because the scan names it:
  - From `Sources/LauncherPlatform/BundleInstall.swift`, bodies unchanged, keeping the name `enum BundleInstall` so the moved tests need only their import changed: `archivedBundleName`, `quarantine`, `newFolder(near:)`, `extract(_:into:)`, `admitted(path:data:)`, `unpack(_:near:)`, `admits(path:kind:linkTarget:)`, `discard(_:)`, `clearQuarantine(under:)`. Also `enum ArchiveEntryKind` and `private final class MemoryStream`.
  - From `GitHubReleases.swift`: `archiveName(_:)` (the asset-name parse, "TrackpadLauncher-<version>-macOS-<minimum>.aar"), body unchanged, as a free or namespaced function.
  - From `CodeSignature.swift`: the `developerID` requirement string, `isGenuine`, `signingInformation(of:)`, and `struct Signer`. `isGenuine` takes `version: Version, minimumMacOS: Version` in place of `as release: Release`, since `Release` stays behind; the body is otherwise unchanged, and its last line compares against those two parameters.
  - One new public entry, the verdict:

```swift
/// The card's rules, whole, on one archive file. nil: every shipped card would install it. Otherwise why not, for a person.
public func refusal(ofArchive archive: URL, team: String, identifier: String) -> String?
```

  In order: the file's name parses with `archiveName`; its bytes read with `Data(contentsOf:)`; `BundleInstall.unpack` into a fresh folder near the temporary directory (every entry admitted, the bundle present); `isGenuine` with the name's version and minimum and `Signer(team:identifier:)`. The unpacked folder is always discarded before returning. `Signer` needs an internal or public init that works here.

- `LauncherKit/Sources/card-contract/main.swift`: thin. Parses `card-contract <archive> --team <team> --identifier <identifier>`, calls `refusal`, and on a refusal or bad usage writes one line to standard error with `FileHandle.standardError.write(Data(...))` and exits non-zero. Accepted: exit 0, nothing written. **Standard output stays empty** in every case: the scan bans `print(` under `Sources`.
- `LauncherKit/Tests/CardContractTests/`: copies of `Tests/LauncherCoreTests/VersionTests.swift`, `Tests/LauncherPlatformTests/BundleInstallTests.swift` (only the tests over code you copied, which today is all of them) and `Tests/LauncherPlatformTests/CraftedArchive.swift`, **expected values unchanged**, only imports changed to `CardContract`. The originals stay until the next slice. Their helpers (`BundleFixture`, `UpdateFixtures`) are in `Tests/LauncherPlatformTests`; copy only what is needed, and point at the existing `Tests/LauncherPlatformTests/UpdateFixtures` folder rather than copying the fixture bundles.

### `Scripts/release.sh`

After `archive_and_check "$APP" strict` in the full release:

```bash
# After archive_and_check strict: the stapled archive, against every shipped card's own rules (R16).
swift run --package-path "$ROOT/LauncherKit" --disable-keychain card-contract \
  "$AAR" --team "$TEAM_ID" --identifier "$BUNDLE_ID" || fail "an older copy's card would refuse this release."
```

In `--archive-only`, after `archive_and_check "$2" lenient`, run the same tool and report its verdict without failing, as the stapler check does there: on `--archive-only` the app is not notarised, so a refusal is expected. A note line, then exit 0.

### `SourcePolicyTests.swift` (in `Tests/LauncherCoreTests`)

`CardContract` sits under `Sources`, so the scan binds it. Add `CardContract.swift` to `onlyIn` in the rows: `AppleArchive`, `ArchiveStream`, `ArchiveByteStream`, `SecCode`, `SecStaticCode`, `SecRequirement`, `Data(contentsOf:`, `removeItem(`, `itemReplacementDirectory`, `removexattr`. Keep the existing files in those rows; the next slice narrows them. Add `CardContract` to the list in `scanVisitsEveryLibraryTarget`. Add T50's test.

Watch the scan's plain substring matches inside `CardContract.swift` and `main.swift`: no `print(`, `curl`, `http`, `Timer`, also in comments.

## Rules that apply

- `docs/architecture.md`, Shape: "`CardContract` and its `card-contract` tool hold a frozen copy of what every shipped update card demands of a release; the release runs them, and the app never links them."
- `docs/architecture.md`, Distribution: "That asset name, the one bundle in it, `TrackpadLauncher.app`, and the repository's path are a contract with every shipped version's update card, and every release runs `card-contract` on the archive to keep it."
- `docs/architecture.md`, Privacy: "No logging of any kind in our code (`print`, `NSLog`, `os_log`, `Logger`)"; and "A source-scan test in `LauncherCoreTests` fails the build on any banned API; add to its list rather than adding prose."
- `docs/architecture.md`, Concurrency: "`LauncherCore` and `LauncherPlatform` are nonisolated by default". `CardContract` is a plain nonisolated library, Swift 6 language mode.
- Tests use Swift Testing. Do not commit: the orchestrator commits your work.
- Worktree guard: write each Bash command with literal arguments, no shell variables, `$(…)` or loops; create and edit files with Write and Edit; absolute paths.

## Starting point

S1: `LauncherKit/Package.swift` depends on Sparkle 2.10.1 exactly, on `LauncherPlatform` only; `Package.resolved` is committed. `Scripts/test.sh` runs `swift test --disable-keychain`. Every `xcodebuild` passes `-packageAuthorizationProvider netrc`. No departures from the plan. Baseline: 709 tests in 68 suites pass.

## Done when

- A diff shows the moved code's bodies unchanged, apart from `isGenuine`'s two parameters.
- The tool reports through standard error and its exit code, and passes the scan.
- `project.yml` does not link the new targets.
- A failing verdict stops a release. On `--archive-only` it is reported and the script goes on, as the stapler check does there.
- Nothing is removed from `LauncherCore` or `LauncherPlatform`.
- The quick gate, `Scripts/test.sh`, is green. It takes minutes: use a long Bash timeout (up to 600000 ms) or `run_in_background`.

# S1: Overlay panels take their content from the subclass

## Goal

`OverlayPanel` stops wrapping its content in rounded glass itself. It takes a ready content view through `init(content:)`, and today's rounded `.regular` glass in `roundedClip` becomes a free helper, `roundedGlass(_:cornerRadius:)`, which both switchers call for now. Nothing looks or behaves differently; this is the prefactor that lets the next slice give the app switcher its own content (a glass container, no panel).

## Requirements

None. This is a prefactor.

## Design

Files: `LauncherKit/Sources/LauncherUI/OverlayPanel.swift`, `LauncherKit/Sources/LauncherUI/GlassClip.swift`, `LauncherKit/Sources/LauncherUI/SwitcherPanel.swift`, `LauncherKit/Sources/LauncherUI/WindowSwitcherPanel.swift`.

```swift
class OverlayPanel: NSPanel {
    init(content: NSView)   // the window configuration, present, the fade and generation as today
}
/// Today's `.regular` glass in `roundedClip`, now the window switcher's own choice.
func roundedGlass(_ content: NSView, cornerRadius: CGFloat) -> NSView
```

- `init(content:)` is the designated initialiser. It keeps every window setting it sets today (borderless, non-activating, clear, shadowed, click-through, `.screenSaver` level, collection behaviour, `hidesOnDeactivate = false`, `animationBehavior = .none`, `isReleasedWhenClosed = false`) and sets `contentView = content` as given. `present`, `dismiss`, the 150 ms fade, the generation guard and `emptied()` are unchanged.
- `roundedGlass(_:cornerRadius:)` builds exactly what `OverlayPanel.init` builds today: an `NSGlassEffectView` with `.regular` style and the corner radius, `contentView = content`, returned through `roundedClip(glass, cornerRadius:)`. Put it in `GlassClip.swift` next to `roundedClip`.
- `WindowSwitcherPanel` calls `super.init(content: roundedGlass(content, cornerRadius: look.panelRadius))`. `SwitcherPanel` calls `super.init(content: roundedGlass(content, cornerRadius: Self.cornerRadius))`. `SwitcherPanel` is rewritten wholesale in the next slice, so change only its init line.
- Update `OverlayPanel`'s doc comment: the content is now the subclass's; drop "Its content is Liquid Glass under `roundedClip`".

## Rules that apply

- `docs/architecture.md`, Concurrency: "`LauncherUI` and the app target use main-actor default isolation." Keep the helper a plain main-actor free function.

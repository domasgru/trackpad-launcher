# S4: Cancelled, refused and failed downloads leave nothing behind

## Goal

`ApplicationsUpdater` handles everything other than a clean install, and proves it at its own seam:
- *Cancel* stops the real download, including at the moment the archive arrives;
- a lost connection, a 30 s stall or a wrong length fails the download;
- an archive that holds anything but the app is refused before verification;
- an app that is not genuine, or not the version offered, is refused before any prompt;
- the administrator's prompt comes only after verification, and cancelling it gives `.declined`.

Each case leaves the running version installed and nothing of the download on disk. Most of the adapter exists from S3; this slice completes and hardens `ArchiveDownload`'s length and stall rules, `cancelDownload()` with its check past the download, and the install step's refusals and discards, and adds the rows below. Fix whatever the rows expose.

- **R7** (part): "*Cancel* MUST stop the download and return the card to "Version <version> is available" with *Update now*, with nothing changed."
- **R8.** "Trackpad Launcher MUST install a downloaded version only when it is signed with the same Developer ID as the running one, notarised by Apple, has the same bundle identifier, and is the version the card offered. Otherwise it MUST install nothing and show the failed state (R12)." Scenarios: a tampered download (signature does not match) and a wrong version downloaded (offered 1.1.0, the app is 1.0.5) → nothing installed, the old version keeps running.
- **R11.** "When the user's account cannot write to /Applications, the update MUST ask for an administrator's name and password, as the move dialog does. The prompt MUST appear after the download finishes and is verified, never before. Cancelling that prompt MUST return the card to "Version <version> is available" with *Update now*, with nothing changed and no error."
- **R12** (the adapter's part): "When a download or install fails for any reason other than R7's *Cancel* or R11's cancelled prompt, the card MUST read "The update couldn't be installed." ... A download that makes no progress for 30 seconds MUST count as failed. ... A failure before the new version is in place MUST leave the running version installed and working. ... On a failure and on a cancel, the downloaded file MUST be deleted."
- **R13** (part): "Closing the settings window or pressing *Quit Trackpad Launcher* while a download runs MUST cancel the download and change nothing." *Cancel* against the archive's arrival.

## Design

The port contract `ApplicationsUpdater` must honour (`Ports.swift`):
- `update(to:events:)`: events in this order: any `.progress`; then `.failed`, or `.downloaded` followed by exactly one of `.installed`, `.declined`, `.failed`. 30 s without a byte fails. /Applications changes only with `.installed`. On every outcome nothing of the update is left on disk except the installed app.
- `cancelDownload()`: before `.downloaded`, stops the download, and no further event arrives. From `.downloaded` on: does nothing.

How (already sketched in S3's code; verify and complete):
- **The download** (`GitHubReleases.ArchiveDownload` in `GitHubReleases.swift`): the archive is received into memory; nothing is written until all of it has arrived, so a *Cancel*, *Close*, Quit, crash or logout mid-download leaves nothing on disk. A body longer or shorter than the size the list declared fails (nil); cancel the task as soon as `countOfBytesReceived` exceeds the declared size. Any status but 200 fails. 30 s with no byte fails through the request's own idle timeout (`timeoutIntervalForRequest = stall`), which every byte resets (probed: a stalled body fails after the interval; a trickle slower in total but never idle that long completes). Task cancellation cancels the request (`withTaskCancellationHandler`), so the server sees the connection close.
- **Cancel against arrival**: the adapter's `.downloaded` push and its cancellation check run in one main-actor turn (`guard !Task.isCancelled` right before `isPastDownload = true; events(.downloaded)`). Either a *Cancel* lands first and nothing more happens, or the install has begun and `cancelDownload()` does nothing.
- **Unpack** (`BundleInstall.unpack`): the archive's selection hook checks every entry before it is written with `admits`; only a relative path equal to or under `TrackpadLauncher.app/` with no `..` component, that is a directory, a regular file, or a symbolic link whose target resolves inside the bundle, is admitted. The first refused entry cancels the extraction and the staging folder is discarded. Nothing outside the staging folder is written before verification.
- **Genuineness** (`CodeSignature.isGenuine`) runs before any prompt; a refusal discards the staging folder and reports `.failed`.
- **The swap** is `ApplicationsInstaller.put` (S1): writable → in-process atomic swap; otherwise the administrator's atomic exchange, so the prompt comes only here. `.cancelled` → `.declined`; `.failed` → `.failed`; `put` discards the staged copy and its folder on every non-installed outcome.

## Rules that apply

- `docs/architecture.md`, Privacy: "No files written other than: settings in `UserDefaults`; the app's own bundle copied into /Applications when the user chooses *Move to Applications*; a newer version, unpacked from memory into a staging folder beside /Applications and swapped in when the user chooses *Update now*."
- Concurrency: "No timers, no polling, no background loops: every input is a push ... Time passes only on Core Animation's clock, and in one network request's own idle timeout (30 s without a byte, reset by every byte, the system's and not a timer of ours)." No `Timer`, `asyncAfter`, `Task.sleep` in shipped sources (tests may wait).
- Source scan (`SourcePolicyTests.swift`), substring per line, comments included: `URLSession`/`http` only in `GitHubReleases.swift`; `copyItem(`/`moveItem(`/`replaceItemAt(`/`removeItem(`/`AppleArchive`/`ArchiveStream`/`ArchiveByteStream`/`removexattr`/`itemReplacementDirectory` only in `BundleInstall.swift`; `SecCode`/`SecStaticCode`/`SecRequirement` only in `CodeSignature.swift`; `.write(to:`, `createFile(atPath`, `FileHandle(forWriting`, `Process()`, `executableURL`, `String(contentsOf:` banned. No logging.
- Do not weaken `isGenuine`, the length rule or the admission rule to make a row pass.

## Starting point

- `ApplicationsUpdater.swift` (unpack → verify → swap → open), `BundleInstall.unpack` / `admits` (an in-memory byte stream; `admits` is stricter than the plan: a symlink must resolve strictly inside the bundle, so a link to the bundle root or one climbing above the app folder is refused), `CodeSignature.isGenuine` (uses the raw bit `1 << 29` for `kSecCSNoNetworkAccess`, which Swift does not import), `GitHubReleases.ArchiveDownload`.

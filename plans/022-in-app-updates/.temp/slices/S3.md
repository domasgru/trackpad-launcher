# S3: Update now replaces the app and reopens it

Worktree: `/Users/dominykasgrubys/code/trackpad-launcher/.claude/worktrees/022-in-app-updates` (branch `feature/022-in-app-updates`). Do not commit; the orchestrator commits your work. Do not switch branches. Use absolute paths. Package root: `LauncherKit/`. App target: `TrackpadLauncher/`.

## Goal

*Update now* downloads the new version into memory, with a filling bar and *Cancel*. It then unpacks and verifies the new version, swaps it into /Applications, opens it as a new process with its settings window, and ends the old one. *Cancel*, *Close* and *Quit* during the download keep the current version. While the update installs, *Quit Trackpad Launcher* is greyed and does nothing, ordinary quits only close the window, and *Close* lets the install finish. A failure shows the failed card with *Try again*, and a cancelled administrator prompt returns to *Update now*.

## Requirements

- **R1** (part): every opening checks, "including the one an update opens (R9), except an opening while an update installs (R7's installing state): the card then keeps showing the install, and that opening makes no check."
- **R3** (the download's request): "The request MUST carry nothing that identifies the user, the Mac, the app's version or the macOS version ... Beyond [the address, time and system-added transport headers], the request's address, the headers Trackpad Launcher sets, and the body MUST be the same on every Mac and every version. Trackpad Launcher MUST write nothing to disk for updates other than the downloaded update (R7), which it MUST delete once the update is installed, cancelled or failed, and the installed app."
- **R7.** "Pressing *Update now* MUST turn the card into its downloading state: the text "Downloading version <version>…", a progress bar that fills as the download goes, and a *Cancel* button. *Cancel* MUST stop the download and return the card to "Version <version> is available" with *Update now*, with nothing changed. When the download finishes, the card MUST enter its installing state: the text "Installing version <version>…", with no progress bar and no *Cancel*. *Cancel* MUST exist only in the downloading state."
- **R8** (a genuine update installs): "Trackpad Launcher MUST install a downloaded version only when it is signed with the same Developer ID as the running one, notarised by Apple, has the same bundle identifier, and is the version the card offered. Otherwise it MUST install nothing and show the failed state (R12)."
- **R9.** "Once a genuine download finishes, Trackpad Launcher MUST replace the copy in /Applications with the new version, stop the old version and open the new one with its settings window open. Gestures MUST keep working until the old version stops. The reopened window MUST make an update check (R1), and MUST show no update card when the installed version is the latest."
- **R10.** "Every setting, starting at login and the Accessibility and Screen Recording permissions MUST carry over to the new version. The new version MUST show no permission prompt and no first-run step."
- **R11** (the model's side): "Cancelling that prompt MUST return the card to "Version <version> is available" with *Update now*, with nothing changed and no error." The prompt appears only after the download finishes and is verified.
- **R12** (the model's failure and *Try again*): "When a download or install fails for any reason other than R7's *Cancel* or R11's cancelled prompt, the card MUST read "The update couldn't be installed." with a *Try again* button. ... *Try again* MUST start the update again, as *Update now* does. A failure before the new version is in place MUST leave the running version installed and working. When the new version is in place but macOS does not open it, the card MUST read the same failed text with *Try again*, the running version MUST keep working until it ends, and *Try again* MUST put the new version in place again and open it."
- **R13.** "Closing the settings window or pressing *Quit Trackpad Launcher* while a download runs MUST cancel the download and change nothing. During the installing state, *Quit Trackpad Launcher* MUST be disabled (greyed out), and every other ordinary quit, *Close Settings* (⌘Q) in the app menu and *Quit* in the Dock icon's menu, MUST do nothing more than close the settings window. *Close* MUST close the window while the install continues, and the new version then opens with its settings window open. Logging out, restarting and shutting down MUST still end Trackpad Launcher, leaving either the old or the new version whole in /Applications."
- **R14** (part): the release's archive unpacks whole.

## Design

### Ownership

`Updater` owns every update decision: the R1 trigger and dropping a stale check; choosing the offer; the download's cancel rules; what each outcome does to the card; whether an install is under way; when the hand-over is done. Public surface: `card`, `isInstalling`, `updateNow()`, `cancel()`. Internal to `LauncherCore`: `windowOpened()` and `windowClosed()` (only `Launcher` calls them) and `onReplaced` (set only by `Lifecycle`). It follows the `StartAtLogin` precedent: one object built by the composition root and shared, each holder using a different part.
- `Lifecycle` reads `isInstalling` in its one exhaustive quit switch, and answers `onReplaced` with `end()` (the settable-callback idiom the ports use).
- Port `UpdateInstaller` hides replacing this copy, in three methods: `update(to:events:)` runs the whole sequence (download into memory, the 30 s stall rule, the length check, the safe unpack, genuineness, the writability check, the administrator prompt, the atomic swap, every clean-up); `cancelDownload()` stops it before the download ends; `openNewVersion(then:)` hides the LaunchServices configuration. The model never holds a file path, so no caller can forget to delete the download.
- Asynchronous delivery keeps model tests synchronous: `@escaping @MainActor` sink; the model sets its phase **before** calling, since an in-memory adapter may answer inline. Real adapters start a `Task` awaiting `@concurrent` statics and call back on the main actor.

### Core types and the port (add to LauncherCore; ports go in `Ports.swift`)

```swift
/// What an update reports, in this order: any `.progress`; then `.failed`, or `.downloaded` followed by exactly one of
/// `.installed`, `.declined`, `.failed`.
public enum UpdateEvent: Equatable, Sendable {
    /// 0...1 of the archive received, in whole percents.
    case progress(Double)
    /// The whole archive arrived. From here on nothing cancels the update.
    case downloaded
    /// /Applications holds the new version.
    case installed
    /// The administrator prompt was cancelled; nothing changed.
    case declined
    /// Nothing changed: the download failed, stalled or had the wrong length; the archive held something else; the
    /// app was not genuine; or the swap failed.
    case failed
}

/// Replacing this copy in /Applications with a newer version, and opening it. Real: ApplicationsUpdater.
/// Test: InMemoryUpdateInstaller.
@MainActor public protocol UpdateInstaller: AnyObject {
    /// Downloads `release`'s archive into memory, then installs it: unpacks it into a staging folder beside
    /// /Applications, checks that it is genuine (this copy's Developer ID team, notarised, this identifier, `release`'s
    /// version and minimum macOS, every resource sealed), and swaps it in for this copy in one atomic step, as an
    /// administrator when this account cannot write there; the prompt comes only at that step. Returns at once;
    /// `events` runs on the main actor, possibly inside this call, in `UpdateEvent`'s order. 30 s without a byte fails.
    /// /Applications changes only with `.installed`. On every outcome nothing of the update is left on disk except the
    /// installed app.
    func update(to release: Release, events: @escaping @MainActor (UpdateEvent) -> Void)
    /// Before `.downloaded`: stops the download, and no further event arrives. From `.downloaded` on: does nothing.
    func cancelDownload()
    /// Opens the copy now in /Applications as a new process, an opening by hand, never a reopen of this one.
    /// `started` runs once, on the main actor: whether macOS started it.
    func openNewVersion(then started: @escaping @MainActor (Bool) -> Void)
}
```

### The whole `Updater` (complete the check half S2 built)

```swift
@MainActor @Observable
public final class Updater {
    /// Every legal situation, and nothing else.
    private enum Phase {
        case idle
        case checking(ticket: Int)
        case offering(Release)
        case downloading(Release, ticket: Int, progress: Double)
        /// Unpacking, verifying, maybe the administrator prompt, the swap. Survives the window closing.
        case installing(Release, ticket: Int)
        /// Swapped in and asked to open; ends with this process.
        case opening(Release)
        case failed(Release)
    }

    private var phase: Phase = .idle
    @ObservationIgnored private var tickets = 0
    @ObservationIgnored private let installed: InstalledRelease
    @ObservationIgnored private let releases: any ReleaseList
    @ObservationIgnored private let installer: any UpdateInstaller
    /// The new version runs: this process ends. Set only by `Lifecycle`.
    @ObservationIgnored var onReplaced: (@MainActor () -> Void)?

    public init(_ installed: InstalledRelease, releases: any ReleaseList, installer: any UpdateInstaller)

    public var card: UpdateCard? {
        switch phase {
        case .idle, .checking: nil
        case .offering(let r): .available(r.version)
        case .downloading(let r, _, let progress): .downloading(r.version, progress: progress)
        case .installing(let r, _), .opening(let r): .installing(r.version)
        case .failed(let r): .failed(r.version)
        }
    }

    /// R13: Quit is disabled and an ordinary quit only closes the window. The one source of that rule.
    public var isInstalling: Bool {
        switch phase {
        case .installing, .opening: true
        default: false
        }
    }

    func windowOpened() {
        guard !isInstalling else { return }  // R1's exemption: the card keeps "Installing…"
        let ticket = nextTicket()
        phase = .checking(ticket: ticket)
        releases.fetch { [unowned self] in checked($0, ticket: ticket) }
    }

    /// A check's result is never kept for the next opening (R1); a download stops (R13); an install continues (R13).
    func windowClosed() {
        switch phase {
        case .downloading:
            phase = .idle
            installer.cancelDownload()
        case .checking, .offering, .failed: phase = .idle
        case .idle, .installing, .opening: break
        }
    }

    /// *Update now* and *Try again* (R7, R12).
    public func updateNow() {
        switch phase {
        case .offering(let release), .failed(let release):
            let ticket = nextTicket()
            phase = .downloading(release, ticket: ticket, progress: 0)
            installer.update(to: release) { [unowned self] in progressed($0, ticket: ticket) }
        default: break
        }
    }

    /// *Cancel*, only while downloading (R7).
    public func cancel() {
        guard case .downloading(let release, _, _) = phase else { return }
        phase = .offering(release)
        installer.cancelDownload()
    }

    private var liveTicket: Int? {
        switch phase {
        case .checking(let t), .downloading(_, let t, _), .installing(_, let t): t
        case .idle, .offering, .opening, .failed: nil
        }
    }

    private func checked(_ list: [Release], ticket: Int) {
        guard ticket == liveTicket else { return }
        phase = Release.newerVersion(in: list, than: installed.version, on: installed.macOS).map(Phase.offering) ?? .idle
    }

    private func progressed(_ event: UpdateEvent, ticket: Int) {
        guard ticket == liveTicket else { return }  // a cancelled or earlier attempt
        switch (phase, event) {
        case (.downloading(let r, _, _), .progress(let fraction)):
            phase = .downloading(r, ticket: ticket, progress: fraction)
        case (.downloading(let r, _, _), .downloaded): phase = .installing(r, ticket: ticket)
        case (.downloading(let r, _, _), .failed), (.installing(let r, _), .failed): phase = .failed(r)  // R8, R12
        case (.installing(let r, _), .declined): phase = .offering(r)  // R11
        case (.installing(let r, _), .installed):
            phase = .opening(r)
            installer.openNewVersion { [unowned self] in opened($0) }  // R9
        default: break
        }
    }

    /// Started: this process ends, and the new version, opened by hand from /Applications, stops anything left.
    /// Not started (R12's last case): /Applications holds the new version; Try again converges (a same-version swap,
    /// a second open).
    private func opened(_ started: Bool) {
        guard case .opening(let r) = phase else { return }
        if started { onReplaced?() } else { phase = .failed(r) }
    }
}
```

`GitHubReleases.swift` gains the download half (keep it in the one network file):

```swift
    /// The download half, used by ApplicationsUpdater, kept here so the network API has one file.
    struct ArchiveDownload: Sendable {
        let stall: TimeInterval
        /// The whole archive, exactly `release.archiveSize` bytes, or nil (failed, stalled, cancelled, wrong length).
        /// `progress` pushes on the main actor, at most once per whole percent. Task cancellation cancels the request.
        func archive(of release: Release, progress: @escaping @MainActor (Double) -> Void) async -> Data?
        // session(accept: "application/octet-stream", stall:); data(for:delegate:) with a task delegate that
        // takes the task in didCreateTask and KVO-observes its progress (a push) → fraction of archiveSize → main;
        // cancel the task once countOfBytesReceived exceeds archiveSize; withTaskCancellationHandler { cancel }.
    }
```
- The archive (about 3 MB) is received **into memory**. Nothing is written until all of it has arrived, so a *Cancel*, *Close*, Quit, crash or logout mid-download leaves nothing on disk. Do not use `download(for:)` (it writes `CFNetworkDownload_*` temp files).
- Progress comes from the task's own progress, observed by KVO (a push), reported in whole percents against the size the list declared. A body longer or shorter than the declared size fails (returns nil). 30 s with no byte fails through the request's own idle timeout (`timeoutIntervalForRequest`), which every byte resets (probed). The app has no timer of its own.
- Same constant headers as the list (`User-Agent: TrackpadLauncher`, `Accept-Language: en`, `X-GitHub-Api-Version: 2022-11-28`) with `Accept: application/octet-stream`, carried across GitHub's one redirect to `release-assets.githubusercontent.com`; same ephemeral, cookie-less, cache-less session, invalidated afterwards.

```swift
/// Replaces the running copy in /Applications with a release, then opens it as a new process.
@MainActor public final class ApplicationsUpdater: UpdateInstaller {
    private let bundle: URL  // Location.running of an `.installed` copy: the bundle an update replaces
    private let signer: Signer
    private let administrator: any Administrator
    /// The whole archive, or nil; `GitHubReleases.ArchiveDownload.archive` when shipped.
    typealias Download = @Sendable (Release, @escaping @MainActor (Double) -> Void) async -> Data?
    private let download: Download
    private var job: Task<Void, Never>?
    private var isPastDownload = false

    public convenience init(replacing bundle: URL, signer: Signer) {
        self.init(replacing: bundle, signer: signer, administrator: AuthorizationAdministrator(),
                  download: GitHubReleases.ArchiveDownload(stall: 30).archive)
    }
    /// Tests: a temp "Applications", TestAdministrator, and a download that is either a local listener's
    /// `ArchiveDownload` with a short stall or a function returning the bytes on the test's own signal.
    init(replacing bundle: URL, signer: Signer, administrator: any Administrator, download: @escaping Download)

    public func update(to release: Release, events: @escaping @MainActor (UpdateEvent) -> Void) {
        isPastDownload = false
        job = Task {
            guard let archive = await download(release, { events(.progress($0)) }) else {
                if !Task.isCancelled { events(.failed) }
                return
            }
            // One main-actor turn: a Cancel either landed before this check (nothing more), or finds the install begun.
            guard !Task.isCancelled else { return }
            isPastDownload = true
            events(.downloaded)
            events(await Self.install(archive, as: release, replacing: bundle, signer: signer, by: administrator))
        }
    }

    public func cancelDownload() {
        guard !isPastDownload else { return }
        job?.cancel()
    }

    public func openNewVersion(then started: @escaping @MainActor (Bool) -> Void) {
        let configuration = NSWorkspace.OpenConfiguration()
        configuration.activates = true
        configuration.createsNewApplicationInstance = true  // by default the old process only gets a reopen (R-3)
        NSWorkspace.shared.openApplication(at: bundle, configuration: configuration) { app, _ in
            let didStart = app != nil
            DispatchQueue.main.async { MainActor.assumeIsolated { started(didStart) } }
        }
    }

    /// Unpack → verify → swap. Nothing interrupts it. Discards the staging folder on every outcome but `.installed`.
    @concurrent private static func install(
        _ archive: Data, as release: Release, replacing bundle: URL, signer: Signer, by administrator: any Administrator
    ) async -> UpdateEvent
    // staged = try BundleInstall.unpack(archive, near: bundle)          else .failed
    // CodeSignature.isGenuine(staged, as: release, signer: signer)      else discard; .failed  (before any prompt: R11)
    // switch ApplicationsInstaller.put(staged, at: bundle, by: administrator) {
    // .installed → .installed; .cancelled → .declined; .failed → .failed }   (put already discards on non-installed)
}
```
- The `.downloaded` push and the cancellation check run in one main-actor turn: either a *Cancel* lands first and nothing more happens, or the model is already `.installing`, where *Cancel* does not exist and closing does not cancel.
- **The effect order is unpack, verify, swap, open, end. The swap is the first change anywhere.** The swap is S1's `ApplicationsInstaller.put` (in-process `BundleInstall.swap` when writable, else the atomic administrator exchange), so the prompt comes only after verification (R11). The destination is `Location.running`, the running bundle, not the move's identifier search.
- **The open**: `createsNewApplicationInstance = true` is load-bearing: when the running app opens its own replaced bundle with the default configuration, LaunchServices only reopens the old process (probed: `plans/022-in-app-updates/.temp/architect/grounding/probes/relaunch/`).

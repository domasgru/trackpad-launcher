# S4: A gated copy checks on its own and holds the update

## Goal

The tracer through every layer. A copy that passes `UpdatableCopy` starts `SparkleEngine` once resident and checks in that same turn. It reveals nothing, downloads silently, and the held update installs at the process's end with no relaunch. The test world gains `InMemoryUpdateEngine` and a release form of a running build. Later slices add the idle minute, the genuineness check, the hand-over and the connection retry on top of this shape, so build only what is below.

## Requirements

- R1 (start and schedule): "A copy signed with a Developer ID in /Applications that can write to its own bundle MUST check for a newer version when it starts, at login or by hand, and every 24 hours while it runs. The check MUST NOT depend on the settings window."
- R2: "A development build, a copy outside /Applications and a copy showing the move dialog MUST make no network request for updates. A development build is a build not signed with a Developer ID. Once a move puts a copy in /Applications, the moved copy checks as in R1."
- R3: "Every request the updater makes, including the download, MUST carry nothing that identifies the user, the Mac, the app's version or the macOS version. Their headers MUST be the same on every Mac and every version. Trackpad Launcher MUST send no system profile, setting or usage data."
- R4 (Sparkle's selection): "A *newer version* MUST be a published full release, with a higher version than the running one, whose minimum macOS this Mac meets. When several count, Trackpad Launcher MUST take the highest. It MUST never install an older version." Selection stays Sparkle's: do not reimplement it.
- R5 (silent download): "Trackpad Launcher MUST download a newer version with no user action. The download MUST show nothing to the user. Gestures MUST keep working during it."
- R12: "A copy that cannot write to its own bundle MUST make no update check and no download, and MUST NOT ask for a password. It checks again at its next start whether it can write."

## Design

### LauncherCore

New `Sources/LauncherCore/Updater.swift` (it was deleted last slice; this is a new, smaller type) holding:

```swift
/// R2 and R12, the gate, whole. Pure, called by the composition root and the tests. Read once, at start.
public struct UpdatableCopy: Equatable, Sendable {
    public init?(placement: Placement, developerIDSigned: Bool, canReplaceItself: Bool) {
        guard developerIDSigned, placement == .installed, canReplaceItself else { return nil }
    }
}

public enum CycleOutcome: Equatable, Sendable {
    /// Up to date, or nothing that could be taken.
    case nothingNew
    /// A request failed, the feed's or the archive's. What a lost connection looks like, and what earns R1's retry.
    case requestFailed
    /// Anything else: a refused enclosure, a bad signature, a veto, a held update lost.
    case failed
}

public enum HeldUpdate: Equatable, Sendable {
    /// Our check passed: same Developer ID, identifier, notarised, sealed versions equal the offer.
    case genuine
    /// It failed, or could not be run. Fail closed.
    case notGenuine
}

public enum UpdateEngineEvent: Equatable, Sendable {
    /// Sparkle verified, extracted and prepared an update, and will install it at this process's end. Pushed inside the
    /// delegate call, so nothing else runs on the main actor first.
    case held(HeldUpdate)
    /// A cycle ended: no update, a failure, or a held update lost (a helper died).
    case cycleEnded(CycleOutcome)
}

/// Owns every update decision. Exists only for a copy the gate lets through.
@MainActor public final class Updater {
    /// The process must end now, through `end()`. Set once by `Lifecycle`.
    public var onHandOver: (@MainActor () -> Void)?
    public init(_ copy: UpdatableCopy, engine: any UpdateEngine)
    /// Once, from a resident only. Starts the engine and checks in the same turn: the one moment Sparkle's docs bless,
    /// and the only way to check at every start, because Sparkle's scheduler checks at start only past 24 hours.
    public func start(watching launcher: Launcher, opening: Opening)
}
```

`Updater` is not `@Observable`: nothing renders it. It shows an initializer, `start` and `onHandOver`, with no version in it. In this slice it subscribes to `engine.onEvent` and acts on no event yet: `.held` and `.cycleEnded` do nothing, in a `switch` that later slices fill. `launcher` and `opening` are unused until later slices; keep the signature. Do not add a phase enum, `Connection` or `IdleClock`: other slices add those.

In `Sources/LauncherCore/Ports.swift`:

```swift
/// Sparkle, and the restart that follows it. No Sparkle type, feed value or version crosses this port.
/// Real: SparkleEngine. Test: InMemoryUpdateEngine.
@MainActor public protocol UpdateEngine: AnyObject {
    var onEvent: (@MainActor (UpdateEngineEvent) -> Void)? { get set }
    /// Makes no request before this call. Starts the 24-hour schedule.
    func start()
    /// One background check.
    func check()
    /// Stops the held update installing. Best effort, two layers; if both fail it installs at this process's end.
    func discardHeldUpdate()
    /// Arms the start of whichever version /Applications holds once this process has ended. The caller ends the
    /// process in the same turn. False: nothing is armed.
    func armRestart() -> Bool
}
```

`Lifecycle` (`Sources/LauncherCore/Lifecycle.swift`):

- `init` gains `updater: Updater? = nil`, stored `@ObservationIgnored private let`. In `init`: `updater?.onHandOver = { [unowned self] in handedOver() }`.
- `private func handedOver() { guard case .resident = stage else { return }; end() }`. `end()`, never `quit()`, so starting at login stays as it is.
- `Stage.replacingOthers` becomes `replacingOthers(opening: Opening, opensWindow: Bool, eject: DiskImage?)`, kept through `openedAgain`, so `othersExited` can pass it on. `replace` takes the opening.
- `othersExited`, the only place the updater starts, so a copy about to end, or asking to move, never reaches the network:

```swift
private func othersExited() {
    guard case .replacingOthers(let opening, let opensWindow, let eject) = stage else { return }
    let launcher = makeResident()
    launcher.start()
    stage = .resident(launcher)
    if opensWindow { launcher.openedByHand() }
    if let eject { installer.eject(eject) }
    updater?.start(watching: launcher, opening: opening)
}
```

`Launcher` does not change and knows nothing about updates.

### LauncherPlatform

New `Sources/LauncherPlatform/SparkleEngine.swift`, the only file with `import Sparkle`:

```swift
/// `internal import Sparkle` lives in this file and nowhere else. SPUUpdater, SPUUserDriver and SPUUpdaterDelegate are
/// NS_SWIFT_UI_ACTOR, so main-actor classes conform with no escape hatch. The delegate is a private object, held here
/// because SPUUpdater keeps it weakly: a public conformance would put a Sparkle type on LauncherPlatform's surface.
@MainActor public final class SparkleEngine: UpdateEngine {
    public var onEvent: (@MainActor (UpdateEngineEvent) -> Void)?
    /// Reads the downloads prefix now: after a swap, `Bundle.main` reads the new bundle.
    public init(bundle: URL, signer: Signer)
    /// R12's predicate.
    public nonisolated static func canReplace(_ bundle: URL) -> Bool { SparkleInternals.canReplace(bundle) }

    public func start() {
        // HTTPCookieStorage.shared.cookieAcceptPolicy = .never                     // before the first request
        // URLCache.shared = URLCache(memoryCapacity: 0, diskCapacity: 0)           // no Cache.db on disk
        // let updater = SPUUpdater(hostBundle: .main, applicationBundle: .main, userDriver: driver, delegate: delegate)
        // updater.userAgentString = "TrackpadLauncher"
        // updater.httpHeaders = ["Accept-Language": "en", "Accept-Encoding": "gzip"]
        // do { try updater.start() } catch { onEvent?(.cycleEnded(.failed)) }      // an empty key lands here, silently
    }
    public func check()               // updater.checkForUpdatesInBackground()
    public func discardHeldUpdate()   // empty in this slice; a later slice writes it
    public func armRestart() -> Bool  // false in this slice; a later slice writes it

    /// nil and SUNoUpdateError are `.nothingNew`; SUDownloadError is `.requestFailed`; everything else `.failed`. Public
    /// codes: every failure of a request, feed or archive, reaches this level wrapped in SUDownloadError.
    nonisolated static func outcome(of error: (any Error)?) -> CycleOutcome
}
```

**A failed start must make no request.** The engine keeps its `SPUUpdater` only once `start()` succeeded, so a later `check()` after a failed start does nothing. `Updater.start` calls `check()` right after `start()`, and the empty key makes `start()` throw in every build until a human creates the update key.

The private delegate (`NSObject, SPUUpdaterDelegate`, main actor), with these three methods only:

- `updater(_:shouldProceedWithUpdate:updateCheck:) throws`: runs before any download. Throws (any `NSError`) unless `isPinned(enclosure: item.fileURL, under: prefix)`. This keeps the disk-image key-rotation fallback unreachable, so R6's update-key half has no second door.
- `updater(_:willInstallUpdateOnQuit:immediateInstallationBlock:) -> Bool`: **always returns true, and the handler is dropped unused**, so Sparkle's relaunch flag can never be set and the only way an install runs is at the process's end. In this slice it pushes `onEvent?(.held(.genuine))`. A later slice inserts the real check before that push.
- `updater(_:didFinishUpdateCycleFor:error:)`: `onEvent?(.cycleEnded(outcome(of: error)))`.

`SilentUserDriver`, private, main actor, `NSObject, SPUUserDriver`: required by the initializer and shows nothing. Every method does no UI. A permission request answers automatic checks true, automatic downloads true, system profile false. Anything that takes a reply of `SPUUserUpdateChoice` answers `.dismiss`; acknowledgements are called. No log lines. The whole list of methods, as Sparkle 2.10.1 requires them, is in `plans/039-auto-updates/.temp/architect/checks/sparkle/SpikeHost.swift`, class `SilentDriver`. That file is a working sketch of every Sparkle call; the delegate signatures there compile.

In the same file:

```swift
/// Every fact here is Sparkle's private business, proven on `provenOn`. Each names its proof. A test compares
/// `provenOn` with LauncherKit/Package.resolved, so an upgrade cannot land without re-proving this type.
enum SparkleInternals {
    static let provenOn = "2.10.1"
    /// Read-only: bundle writable, parent writable, bundle owned by this user, and its group one of this user's.
    /// Sparkle's rule proves the last two by chowning a temporary file; this creates nothing. A stricter future Sparkle
    /// costs a silent download at each check, never a prompt.
    nonisolated static func canReplace(_ bundle: URL) -> Bool
}

/// Under `prefix`, ending in `.aar`, with no `..`. A missing prefix admits nothing. The prefix is the Info.plist key
/// `TLUpdateDownloads`, so no address exists in Swift and a local server can stand in for GitHub; that the shipped key
/// is `https` is the scan's rule, `alwaysDeclared`, not this function's.
func isPinned(enclosure: URL?, under prefix: String?) -> Bool
```

`isPinned` works on the whole URL string against the prefix, on the URL's path for `.aar` (so `x.dmg?.aar` is refused), and refuses `..` both plain and percent-encoded.

`canReplace` uses `access`/`stat` and the user's groups (`getgroups` or `getgrouplist`), and creates no file. This matters: an admin looking at another admin's copy, and a group-writable `root:admin` copy, must read false.

`Signer` and `ExpectedUpdate` already exist in `CodeSignature.swift`. Sparkle's headers are at `LauncherKit/.build/artifacts/sparkle/Sparkle/Sparkle.xcframework/macos-arm64_x86_64/Sparkle.framework/Headers`.

Sparkle's selection is used as it is: it filters by minimum macOS and takes the highest build. The XPC services stay in the bundle unused; nothing strips a signed framework. No `SPUStandardUpdaterController`.

### App target

`TrackpadLauncher/TrackpadLauncherApp.swift`, in `applicationWillFinishLaunching`, because that is where the gate reads the running copy. Building it does nothing: `SparkleEngine.start` creates the `SPUUpdater`.

```swift
// The gate is a value only `UpdatableCopy.init?` can make, and `Updater` will not build without one.
private func makeUpdater(placement: Placement, location: Location) -> Updater? {
    let signer = CodeSignature.developerIDSigner()
    guard
        let copy = UpdatableCopy(
            placement: placement, developerIDSigned: signer != nil,
            canReplaceItself: SparkleEngine.canReplace(location.running)),
        let signer
    else { return nil }
    return Updater(copy, engine: SparkleEngine(bundle: location.running, signer: signer))
}
```

`developerIDSigner()` takes no arguments, so `--as-release-build` cannot fake it. Pass the result to `Lifecycle`.

### Test world

In `Tests/LauncherCoreTests/InMemoryAdapters.swift`, an `InMemoryUpdateEngine: UpdateEngine` with `starts`, `checks`, `discards`, `armWorks` (default true), and `push(_ event:)`. Each of `start`, `check`, `discardHeldUpdate`, `armRestart` appends to the `EffectLog` as "engine start", "check", "discard", "arm restart".

In `LifecycleWorld.swift`:

```swift
/// What the process is: `.release` passes the gate wherever it lies, given placement; `.development` does not.
struct RunningBuild { var developerIDSigned: Bool; var canWrite: Bool
    static let development, release; static func release(canWrite: Bool) -> RunningBuild }
```

`launch` gains `running: RunningBuild = .development`, so every existing row is unaffected. `OneProcess` builds `UpdatableCopy(placement:developerIDSigned:canReplaceItself:)` exactly as the composition root does, and an `Updater` over a fresh `InMemoryUpdateEngine` when the gate passes. It exposes `engine` and `updater` (nil when gated out). The engine exists either way, so "no engine call" reads as `engine.starts == 0`.

- `docs/architecture.md`, Concurrency: "`LauncherCore` and `LauncherPlatform` are nonisolated by default; the model, the ports and the public surface of every real adapter are `@MainActor`."

- `docs/domain-model.md`, Update check: "A development build, a copy outside /Applications, a copy showing the move dialog and a copy that cannot write to its own bundle never check, and the last checks again at its next start whether it can write."

# S3: The no-windows card

## Goal

With *Switch windows* on and Accessibility granted, a slide up or down over an app with zero or one window now shows the window switcher with a single card that names the app. The same holds for an app with a full-screen front window, an app whose only window is minimised, and Trackpad Launcher itself.
- The card follows the fingers a few points, then settles back.
- Lifting or cancelling changes nothing and is silent.
- No frontmost app, or no answer within 0.2 s, still declines the slide: it scrolls, as today.

Repo background: a macOS trackpad launcher, built as a SwiftPM package in `LauncherKit/`:
- `LauncherCore`: the pure model and its ports;
- `LauncherPlatform`: the adapters;
- `LauncherUI`: the AppKit shell.

`plans/042-window-stacks-switcher-order/.temp/exploration.md` maps the code as it stood before S1. The Starting point section says what S1 and S2 changed.

## Requirements

**R10. An app with zero or one window shows the no-windows card.**
> While the window swipe setting is on and Trackpad Launcher has the Accessibility permission, two fingers sliding up or down under an anchored thumb MUST be a window swipe whenever the frontmost app has zero or one window. That includes an app whose front window is in full screen. The window switcher MUST then show a single card in place of the rows. The card MUST show the app's icon on the left, like a row's preview, and two lines of text. The first line MUST be bold and the second line regular weight. With one window, the first line reads "No other windows" and the second "‹App› has no other windows on this desktop." With zero windows, the first line reads "No open windows" and the second "‹App› has no windows on this desktop." ‹App› is the app's name. The slide MUST then follow every other window swipe rule: no scrolling, no clicks, no system trackpad swipes, until the fingers lift.

**R11. The card follows the fingers a little.**
> The card's offset MUST track the fingers' up or down movement since their last change of direction, damped, and clamped at 6 pt above or below its resting place. Sliding further MUST NOT move it further. When the fingers change direction, the card MUST at once move toward the new direction, passing its resting place and going up to 6 pt beyond it. When the fingers lift, it MUST settle back as the switcher goes. The card MUST play no haptic while it moves. With *Reduce motion* on, the card MUST stay still.

**R12. Lifting on the card changes nothing.**
> Lifting on the card MUST leave every window and app as it was. It MUST be silent, with no haptic. With the hide background apps setting on, it MUST hide nothing. A cancelled window swipe on the card MUST be silent too.

**R13. No card without a known window count.**
> When there is no frontmost app, or the frontmost app does not answer (it has not reported its windows within 0.2 s), the slide MUST be no window swipe: nothing shows, and the slide scrolls as an ordinary two-finger slide, as today. Without the Accessibility permission, the same MUST hold.

## Design

### LauncherCore: rows or the card (`WindowSwitcher.swift`, `WindowLift.swift`, `Copy.swift`, `SwitcherSelection.swift`)

```swift
public struct WindowSwitcher: Equatable, Sendable {
    public struct Content: Equatable, Sendable {
        public let app: AppEntry
        public let list: List
    }

    public enum List: Equatable, Sendable {
        /// Two to ten windows, in the app's window order.
        case rows(Rows)
        /// Zero or one window: the no-windows card in place of the rows.
        case card(NoWindowsCard)
    }

    // Rows: unchanged from S2.

    public let content: Content
    /// Rows: one item per row, starting on `startRow`. The card: one item, so it rubber-bands both ways and crosses
    /// nothing: no light tick, no raise.
    public package(set) var selection: SwitcherSelection
    public let serial: Int
    public let trackpad: TrackpadID
    public let showsPreviews: Bool

    package init(_ content: Content, showsPreviews: Bool, serial: Int, trackpad: TrackpadID)
    //   rows → SwitcherSelection(count: rows.rows.count, startingAt: rows.startRow); card → SwitcherSelection(count: 1)

    public var app: AppEntry { content.app }
    public var isCard: Bool { if case .card = content.list { true } else { false } }
    /// [] for the card.
    public var rows: [Row] { if case .rows(let rows) = content.list { rows.rows } else { [] } }
    /// The visible rows while `showsPreviews`; [] for the card.
    public var previewWindows: [WindowID]
    public var frontWindow: WindowID? { if case .rows(let rows) = content.list { rows.frontWindow } else { nil } }
    /// nil on a minimised row and on the card.
    public var selectedVisibleWindow: WindowID?
    /// The card's offset from rest, in points, positive down; nil for rows.
    public var cardOffset: Double? { isCard ? NoWindowsCard.offset(stretch: selection.stretch) : nil }
}

/// The window switcher's single card for an app with zero or one window (R10): the app's icon on the left, a bold
/// first line and a regular second line.
public struct NoWindowsCard: Equatable, Sendable {
    public enum Kind: Equatable, Sendable { case noWindows, oneWindow }
    public let kind: Kind
    /// "No open windows" / "No other windows".
    public let title: String
    /// "‹App› has no windows on this desktop." / "‹App› has no other windows on this desktop."
    public let message: String
    package init(_ kind: Kind, of app: AppEntry)

    /// The most the card moves from rest, either way.
    public static let maxOffset = 6.0
    /// `maxOffset × stretch / SwitcherSelection.fullStretch`. A one-item selection keeps its travel within a quarter
    /// step of rest and restarts it from a turn, so the offset follows the movement since the last change of direction,
    /// damped by the rubber band's curve, never past 6 pt, and turns at once (R11). Pure.
    public static func offset(stretch: Double) -> Double
}

extension SwitcherSelection {
    /// `stretch` at the full overshoot of a quarter step: about 0.111 items. Compute it from the same formula as
    /// `stretch` with excess = `GestureRules.switcherMaxOvershoot`; do not hard-code the number.
    public static var fullStretch: Double
}

extension Copy {
    public static let noOtherWindowsTitle = "No other windows"
    public static func noOtherWindowsMessage(of app: String) -> String { "\(app) has no other windows on this desktop." }
    public static let noOpenWindowsTitle = "No open windows"
    public static func noOpenWindowsMessage(of app: String) -> String { "\(app) has no windows on this desktop." }
}
```

- **Clamp.** `offset(stretch:)` should also clamp its result to ±`maxOffset`, so floating-point error never passes 6.
- **Sign.** Sliding down is positive travel in the window switcher, so a positive stretch means the card moves down.
- **The lift.** `WindowSwitcher.lift(now:)` gives `.nothing` for the card. It is never reached for the card, but keep it total.

### LauncherCore: `WindowOrders.list` answers with the card

In S2, the guard below two windows returned nil. It now returns the card:

```swift
guard case .app(let app, let launch, let windowRead) = read, let count = windowRead.windowCount else { return nil }
if case .windows(let windows) = windowRead { /* update the order, as in S2 */ }
guard count >= 2, case .windows(let windows) = windowRead else {
    return Content(app: app, list: .card(NoWindowsCard(count == 0 ? .noWindows : .oneWindow, of: app)))
}
return Content(app: app, list: .rows(Rows(app: app, pick: WindowPick(windows), order: ...)))
```

`windowCount` is the deciding count, and it covers these cases:
- **No windows**: 0, which gives `.noWindows`.
- **One window, or a lone minimised one**: 1.
- **A full-screen front window**: `WindowPick` picks it alone, so 1.
- **`.ownProcess`**, Trackpad Launcher's settings window: 1.

`.unanswered` and `.noApp` still give nil, which means no window swipe.

### LauncherCore: `Launcher.windowSwipe`

- **`.began`**: unchanged from S2. A card content is confirmed and shown like rows.
- **`.moved`**: unchanged. The card's one-item selection never crosses an item, so no light tick plays. `selectedVisibleWindow` is nil, so nothing is raised.
- **`.ended`**:
  ```swift
  guard case .windows(let open)? = shown, open.trackpad == event.trackpad else { return }
  shown = nil
  guard !open.isCard else { return }        // R12: no second read, no raise, no haptic, no hide
  let lift = open.lift(now: system.frontmostWindows(within: GestureRules.windowReadDeadline))
  ...as today
  ```
- **`.cancelled`**: as today, which is silent.

### LauncherUI: the card in the window switcher

**`WindowSwitcherPanel` (card mode).**

```swift
/// The card in `WindowColumnLayout(rowCount: 1, …)`'s one row frame: the icon in the preview slot, the bold title
/// and the regular message in the title column (two lines at most, then cut short at the end), the highlight as its plate.
func lay(card: NoWindowsCard, icon: NSImage, layout: WindowColumnLayout, topLeft: NSPoint)
/// Plate and content `offset` points below rest (inside the 8 pt padding); a 0.1 s implicit action when animated.
func moveCard(by offset: Double, animated: Bool)
/// Back to rest over the dismiss fade's 150 ms, or at once; a no-op unless a card is laid out.
func settleCard(animated: Bool)
```

- **Layout.** The title is 13 pt bold, above a 12 pt regular message. The message wraps onto a second line when it must, then is cut short at its end with an ellipsis.
- **Switching modes.** `lay(out:…)` of rows hides the card. `lay(card:…)` hides every row view.
- **Plate.** The highlight's glass is the card's plate.

**`WindowSwitcherPresenter.render`** (S1 gave it `init(reduceMotion:)`, `observe(_:)` and `render(_:)`):

```swift
// a new serial lays out the rows as today, or the card: lay(card:) with the app icon, no capture, no awaited previews,
// then present as today.
switch switcher.content.list {
case .rows: panel.show(position: selection.position, selected: selection.selected)      // + today's spring
case .card: panel.moveCard(by: reduceMotion() ? 0 : switcher.cardOffset ?? 0, animated: !reduceMotion())
}
// render(nil): panel.settleCard(animated: !reduceMotion()); panel.dismiss()
```

## Rules that apply

- **domain-model.md, No-windows card:** "The window switcher's single card in place of its rows when the frontmost app has zero or one window: the app's icon on the left, where a row's preview sits, a bold first line and a regular message. … It shows no preview. It follows the fingers up or down a few points, never more than 6 pt from rest, turning at once when they turn, with no haptic, and settles back as the window switcher goes; with Reduce motion on it stays still. Lifting on it, or cancelling it, changes nothing and is silent: no window moves and, with the hide background apps setting on, nothing hides."
- **domain-model.md, Window swipe:** "It exists whenever the frontmost app's windows are known when the slide's direction is decided, whatever their number … Otherwise the slide is no window swipe: nothing shows, nothing pulses, and it behaves exactly as with the window swipe setting off".
- **domain-model.md, Feedback:** a silent lift includes "a lift on the no-windows card; a cancelled window swipe".
- **domain-model.md, Frontmost app:** "A slide up or down over it [Trackpad Launcher] shows the no-windows card ("Trackpad Launcher has no other windows on this desktop."), since the settings window is its only window."
- **architecture.md, Concurrency:** "Animation is Core Animation keyframes, which the render server plays. Whatever an animation leaves behind is cleaned up from its completion callback. … No code of ours runs per display frame, and display links are banned along with timers. Code may run per input event while the effect it serves is on screen: the switchers' highlight on trackpad frames". `moveCard` runs per trackpad frame, using implicit actions, with no timers.
- **architecture.md, Privacy:** Screen Recording "is used only to take one picture of each listed visible window when a window swipe begins". The card captures nothing.
- **architecture.md, Shape:** "Policy lives in pure functions and value types; the shell stays thin." The offset is computed in Core (`cardOffset`). The presenter only renders it.
- **architecture.md:** "`LauncherUI` and the app target use main-actor default isolation."

**T38 (R11), Core value.**
- `NoWindowsCard.offset(stretch:)` is 0 at 0.
- A one-item `SwitcherSelection` followed 40 mm down reaches a stretch whose offset is 6. Followed 40 mm up, the offset is −6.
- The offset's sign is the stretch's.
- **Source.** R11 "6 pt above or below its resting place".

**T39 (R11), panel bench.** After `lay(card:)`:

- `settleCard(animated: true)` returns them to rest with a 0.15 s animation.
- `settleCard(animated: false)` returns them at once, with no animation.
- With rows laid out, `settleCard` changes nothing.
- **Source.** R11 "settle back as the switcher goes"; the design's 0.1 s action and 150 ms fade.

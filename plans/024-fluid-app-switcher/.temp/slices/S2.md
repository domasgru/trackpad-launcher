# S2: One liquid shape that jumps between icons

## Goal

The app switcher (two fingers sliding sideways under the anchored thumb) stops being a glass rectangle with a sliding highlight. It shows as one Liquid Glass shape: a band under the icons, a bead around each icon, and a bigger swell around the selected icon. A selection change moves the swell straight to the new icon, with no motion. That is the Reduce Motion look, and everyone sees it until a later slice adds render-server motion. The geometry, the look's numbers and the per-swipe `Liquid` model land in LauncherCore, test-first through `World`.

## Requirements

- **R1.** The switcher MUST show as a single continuous shape that encloses every icon in its row, with no rectangular panel around it. *Five running apps:* one unbroken shape surrounds all five icons, and no rectangle frames the row. *One app* (no app is in front, and one other app runs): the shape is a single swell around that one enlarged icon.
- **R2.** The shape MUST look like the system's Liquid Glass, like today's switcher panel, in both light and dark appearance. The swell carries no tint. *Dark:* over a busy window, the shape reads as glass, and every icon and the swell stay clearly visible. *Light over a white window:* the band, each bead and the swell are each distinguishable from the window and from each other.
- **R3.** Around each unselected icon the band MUST form a soft rounded bump, and between two neighbouring icons it MUST narrow into a neck that still joins them.
- **R4.** Around the selected icon the liquid MUST swell clearly bigger than a bead, by 12 pt beyond the beads on each side. The selected icon MUST still be drawn larger than the others (1.12×), and it stays inside the swell. *When the switcher opens,* the first icon, the app in front, sits enlarged in the swell and every other icon sits in a bead.
- **R11 (this slice's part).** The switcher MUST appear the moment the swipe begins, already settled, with the swell around the first icon. There is no grow-in or pour animation. When the switcher closes, the shape fades out over 150 ms, as the switcher does today.
- **R13.** With Reduce Motion on, the shape, beads and swell MUST still show. There MUST be no wave, stretch, flow or wobble: the swell jumps straight to the newly selected icon. *Push past the last app with Reduce Motion on:* the swell stays around the last icon and nothing stretches.
- **R14.** The shape MUST keep its proportions to the icons when the row shrinks to fit a narrow display, so every icon still sits in its bead or swell. The row stays centred on the display under the pointer. *Ten apps on a narrow display:* the icons, beads, swell and band all shrink by the same factor, and the shape still fits on the display.
- **R16 (the still part).** While the liquid is settled and while the switcher is hidden, the liquid MUST NOT redraw or run animation work.
- **R17 (the shape knobs).** The swell's size and the bead and neck shape MUST each be adjustable in one place. Making the swell subtle MUST take changing one setting in that place: lowering the swell size makes the swell rise only a few points beyond the band, and nothing else about the switcher changes.

Unchanged and out of scope: the window switcher's look, `SwitcherSelection`, `GestureRules`, the recognizer, `SwipeEvent`, every port, and `Launcher` (lifting already brings the app to front first).

## Design

### The three values

1. **Geometry: `SwitcherRowLayout(iconCount:displayWidth:look:)`** (LauncherCore, replacing today's in `Sources/LauncherCore/SwitcherRowLayout.swift`). The one geometry source; it carries the `LiquidLook` it was built from. Everything hangs off one `centreX(at:)` and one `scale`.
2. **Motion state: `Liquid`**, one per swipe. In this slice: the last selection fed and the mode.
3. **Output: `LiquidFrame`**: the swell view's new rest (only when the selection moved), the icon to grow, and tracks (always empty in this slice).

### LauncherCore types (new file(s), e.g. `Liquid.swift`, `LiquidLook.swift`)

```swift
/// Every number of the switcher's liquid look and motion, at full size (points, seconds, items). The defaults ARE the
/// shipped look. Requirement bounds are not here: `Liquid` enforces them whatever this holds.
public struct LiquidLook: Equatable, Sendable {
    // Shape (R1–R4; R17 "bead and neck shape")
    public var beadSide = 80.0, beadCorner = 0.32          // corner as a share of the side
    public var bandThickness = 52.0                         // the neck
    public var spacing = 40.0                               // the container's merge distance: how soft the necks' fillets are
    /// THE swell setting (R4, R17): how far the swell rises beyond a bead on each side. 3 is subtle. It moves nothing
    /// else: the scale and the panel come from `room`; the rise is clamped to fit it with the pull.
    public var swellRise = 12.0, swellCorner = 0.32
    /// The panel's clear margin beyond the beads on every side: the swell's rise, R10's pull and the wave's cap live in it.
    public var room = 40.0
    /// The visible body of an 80 pt icon. A wave never dips a bead within 4 pt of it (R8), and the swell never thins
    /// below the grown body plus 4 pt (R4). Checked by hand against real icons.
    public var iconBody = 64.0
    // Stretch, flow, end pull (R5, R6, R10)
    public var reach = 0.5                                  // leading-edge stretch per item of lean
    public var followTime = 1.0 / 60                        // glide between input events (R15)
    public var flowTime = 0.18, leadShare = 0.6             // Liquid caps flowTime at 0.2 s
    public var endPull = 20.0, endPullMM = 1.0              // capped at 0.2 pitch; e-fold per step-mm, so 95% by 3 mm
    public var pullHold = 0.06                              // the pull stays out this long after the last move, then springs back (R10)
    public var thinning = 0.25                              // swell height lost per point of stretch
    // Wobble (R6, R9)
    public var wobble = 4.0, wobbleHz = 4.5, wobbleDamping = 0.35
    // Wave (R8)
    public var waveHeight = 6.0, waveFullSpeed = 8.0        // crest in points at full speed; items per second for full speed
    /// THE wave cap (R8): the most a wave raises a bead's edge beyond its rest, on each side. Its own setting: the
    /// swell's size never lowers it (R17). Clamped to fit `room`.
    public var waveMax = 12.0
    public var waveReach = 2.5, waveSpeed = 14.0            // items to 1/e; items per second along the band
    public var waveHz = 5.0, waveDamping = 0.4, waveBehind = 0.3, waveEvery = 0.5

    public static let shipped = LiquidLook()
    public init() {}
}
```

Add every knob now (later slices use the motion ones), with these defaults. Do not add `Codable` (a later slice adds it, DEBUG-only).

```swift
/// The one geometry source: icons, band, beads and swell all hang off `centreX(at:)` and `scale`, so they cannot drift.
public struct SwitcherRowLayout: Equatable, Sendable {
    public static let fullIconSide = 80.0, fullPitch = 100.0, selectedIconScale = 1.12
    public let iconCount: Int
    public let look: LiquidLook          // one snapshot per swipe
    public let scale: Double
    public init(iconCount: Int, displayWidth: Double, look: LiquidLook = .shipped)

    public var iconSide: Double { Self.fullIconSide * scale }
    public var selectedIconBody: Double { look.iconBody * Self.selectedIconScale * scale }
    public var swellRise: Double         // the rise actually drawn, clamped
    public var pitch: Double { Self.fullPitch * scale }
    public var panelSize: (width: Double, height: Double)
    public func centreX(at position: Double) -> Double
    public var centreY: Double { panelSize.height / 2 }
    public var band: LiquidRect          // first icon centre to last, a capsule; with one icon, exactly the bead
    public func bead(at index: Int) -> LiquidRect   // index ≥ iconCount is a spare, laid exactly over the band
    public func swell(at index: Int) -> LiquidRect  // bead + 2 × rise, same centre
    public var radii: (band: Double, bead: Double, swell: Double)
    public var spacing: Double { look.spacing * scale }
    public var beadLimits: ClosedRange<Double>      // how tall a wave may make a bead (used from S5)
}
```

The rules, every length × `scale` (R14):

- `scale` = min(1, displayWidth / ((n − 1) × 100 + `beadSide` + 2 × `room`)), with n = `iconCount` (treat n < 1 as 1). A non-positive `displayWidth` means 1. It never depends on `swellRise` or `waveMax` (R17). For ten apps the denominator is 900 + 80 + 80 = 1060 pt.
- `panelSize` = (((n − 1) × 100 + `beadSide` + 2 × `room`) × scale, (`beadSide` + 2 × `room`) × scale). Full size, five apps: 560 × 160.
- `centreX(at p)` = (`room` + `beadSide` / 2) × scale + p × pitch, measured from the panel's left edge. `centreY` = half the panel's height.
- `bead(at i)`, i < n: a `beadSide × scale` square centred on (`centreX(i)`, `centreY`). Radius `beadCorner × beadSide × scale` (25.6 at full size).
- `band`, n ≥ 2: from `centreX(0)` to `centreX(n − 1)` wide, `bandThickness × scale` tall, centred on `centreY`; radius half its height (a capsule). n = 1: exactly `bead(at: 0)`, and `radii.band` is then the bead radius.
- `bead(at i)`, i ≥ n: exactly `band` (a spare). The panel gives spare views the band's radius, so identical shapes merge neutrally.
- `swellRise` = clamp(`look.swellRise`, 0, `look.room` − min(`look.endPull`, 0.2 × 100)) × scale. So the shipped 12 stays 12; 30 clamps to 20; 3 is 3.
- `swell(at i)`: `bead(at i)` grown by `swellRise` on every side, same centre (104 pt at full size). Radius `swellCorner × swell side` (33.28 at full size).
- `beadLimits` = (max(`iconBody` + 4, `bandThickness`) × scale) ... ((`beadSide` + 2 × min(`waveMax`, `room`)) × scale): 68 ... 104 at full size. Independent of `swellRise`.

```swift
public struct LiquidRect: Equatable, Sendable { public var minX, minY, width, height: Double }   // panel points, y up from the panel's bottom
/// Seconds on the clock tracks begin on: Core Animation's media time on hardware, frame times in tests.
public struct LiquidTime: Comparable, Sendable {
    public var seconds: Double
    public static func + (t: Self, s: Double) -> Self
}
public enum LiquidMotion: Sendable {
    case flowing   // render-server motion: stretch, flow, wobble, wave, end pull (later slices)
    case still     // Reduce Motion, or the glass mirror is not live: the swell jumps; nothing stretches or ripples (R13)
}

/// The switcher's liquid during one swipe.
public struct Liquid: Sendable {
    public init(layout: SwitcherRowLayout, motion: LiquidMotion)
    public mutating func follow(_ selection: SwitcherSelection, at time: LiquidTime) -> LiquidFrame
    public func shape(at time: LiquidTime) -> LiquidShape
    static let flowBound = 0.2, settleBound = 1.0, endPullBound = 0.2, sampleRate = 120.0   // used from S3
}

public struct LiquidFrame: Equatable, Sendable {
    public var swell: LiquidRect?              // the swell view's new frame; nil = unchanged
    public var icon: IconChange?
    public var tracks: [LiquidTrack]           // at most one per channel
    public var isEmpty: Bool { swell == nil && icon == nil && tracks.isEmpty }
    // plus a `static let empty`
}
public struct IconChange: Equatable, Sendable { public let selected: Int; public let duration: Double }   // 0 under .still
public enum LiquidElement: Hashable, Sendable { case swell, bead(Int) }
public enum LiquidProperty: Hashable, Sendable { case centreX, width, height }
/// A channel holds at most one running track: a new track replaces the old one, which is how motion retargets.
public struct LiquidChannel: Hashable, Sendable { public let element: LiquidElement; public let property: LiquidProperty }
/// Additive offsets in points over the element's rest, `step` seconds apart from `begin`.
public struct LiquidTrack: Equatable, Sendable {
    public let channel: LiquidChannel
    public let begin: LiquidTime, step: Double
    public let offsets: [Double]
    public var holds: Bool { offsets.last != 0 }
}
public struct LiquidShape: Equatable, Sendable { public let band: LiquidRect, beads: [LiquidRect], swell: LiquidRect }
```

Declare the track and channel types now so the frame's shape is final; nothing in this slice produces a track. Add public memberwise initialisers where tests or LauncherUI need them.

`follow` in this slice:

- **The first call** returns the settled opening (R11): `swell: layout.swell(at: selection.selected)`, `icon: IconChange(selected: selection.selected, duration: 0)`, no tracks.
- **A later call whose `selection` equals the last one fed** returns `.empty` (a repeated call, and resting fingers). `SwitcherSelection`'s synthesised `==` includes its travel, so every move event is a new value.
- **Otherwise,** it records the selection. If `selected` changed, it returns `swell: layout.swell(at: selected)` and `icon: IconChange(selected:, duration: 0)`. If not, `.empty`. Under `.still` this is final. In this slice `.flowing` behaves exactly like `.still`; S3 replaces it.
- Every staged rest is the selection fed in that call: an absolute target, never an increment. `Observations` may coalesce values, so the model must not rely on seeing every one.

`shape(at:)`: what the render server shows at `time`. In this slice it is the band, the real beads (`iconCount` of them) and the swell at the current selection's rest, at any time.

### LauncherUI

**`SwitcherPanel`** (rewrite `Sources/LauncherUI/SwitcherPanel.swift`). It renders `LiquidFrame`s and decides nothing.

```swift
final class SwitcherPanel: OverlayPanel {
    /// Internal, not private, so `@testable` tests (S3) can reach the twelve glass views.
    let container = NSGlassEffectContainerView()
    let band = NSGlassEffectView(), beads = (0..<10).map { _ in NSGlassEffectView() }, swellView = NSGlassEffectView()
    init()
    func checkMirror() -> Bool                // this slice: returns false, no work (no mirror yet)
    func lay(out images: [NSImage], layout: SwitcherRowLayout, on screen: NSRect, backingScale: CGFloat)
    func apply(_ frame: LiquidFrame)
    override func emptied()
}
```

- **Content.** `super.init(content: root)`, where `root` is its own layer-backed view holding the container and, above it as a sibling, an icon host view with the icon `CALayer`s. No `roundedGlass` and no `roundedClip`: there is no rectangle any more. The window stays clear, borderless and shadowed (`OverlayPanel` already sets that); the shadow traces the merged shape.
- **Glass.** One `NSGlassEffectContainerView` holds twelve `.regular` glass views, created with the panel and **never added, removed or hidden**: the band, ten beads and the swell (S3's mirror needs that fixed membership). Add them to the container's `contentView`. Add the swell last so it sits on top. No tint on any glass. 10 is `GestureRules.switcherMaxApps`.
- **`lay(out:layout:on:backingScale:)`.** It runs once per swipe, never per event, and laying out twice is harmless. In one `CATransaction` with actions disabled, it does four things:
  - sets the window frame once, centred on `screen` (`screen.midX − width / 2`, `screen.midY − height / 2`);
  - sets every glass view's frame and `cornerRadius` from the layout: band from `band`/`radii.band`, beads 0..<10 from `bead(at:)` (the real ones with `radii.bead`, spares with `radii.band`), the swell from `swell(at: 0)`/`radii.swell`;
  - sets `container.spacing = layout.spacing`;
  - replaces the icon layers with one per image, centred at (`centreX(at: i)`, `centreY`), side `iconSide`, contents drawn as today (bitmap side `fullIconSide × backingScale`, trilinear minification), at scale 1.
  
  Then `invalidateShadow()`. Keep the layout for `apply` and `emptied`.
- **`apply(_ frame:)`.** One `CATransaction` with actions disabled. If `frame.swell` is set, set `swellView.frame` to it. If `frame.icon` is set, grow that icon: the selected icon's layer to `SwitcherRowLayout.selectedIconScale` and every other icon to 1. A duration of 0 means at once; a non-zero duration animates it linearly over that duration (used from S3). Tracks are ignored in this slice. Then `invalidateShadow()` only if a frame changed.
- **`emptied()`** (runs after the fade): put the swell view back at `swell(at: 0)` of the kept layout. No other work while hidden (R16).
- Map `LiquidRect` to `NSRect` with a small `NSRect(_ rect: LiquidRect)` initialiser in LauncherUI. LauncherCore stays free of AppKit types.

**`SwitcherPresenter`** (`Sources/LauncherUI/SwitcherPresenter.swift`). Thin. Keep the icon passes, observers and `Observations` loop as they are. Replace `render`/`open` with this, and drop `lastStretch` and `springHighlight`:

```swift
private func render(_ switcher: Switcher?) {
    guard let switcher else { liquid = nil; return panel.dismiss() }     // 150 ms fade (R11); the lift never waits (R12)
    let now = LiquidTime(seconds: CACurrentMediaTime())                    // Core Animation's clock, read per input event
    if !panel.isPresented || switcher.row != laidOutRow { return open(switcher, at: now) }
    guard let frame = liquid?.follow(switcher.selection, at: now), !frame.isEmpty else { return }   // nothing changed: no commit
    panel.apply(frame)
}

private func open(_ switcher: Switcher, at now: LiquidTime) {
    let screen = Displays.screen(under: NSEvent.mouseLocation)
    let layout = SwitcherRowLayout(
        iconCount: switcher.row.count, displayWidth: Double(screen?.frame.width ?? 0), look: look())   // one snapshot per swipe
    panel.lay(out: switcher.row.map { icons.icon(forSwitcher: $0) }, layout: layout,
              on: screen?.frame ?? .zero, backingScale: screen?.backingScaleFactor ?? 2)
    panel.present(appear: nil)                                             // on screen now, settled (R11)
    let still = NSWorkspace.shared.accessibilityDisplayShouldReduceMotion || !panel.checkMirror()
    var liquid = Liquid(layout: layout, motion: still ? .still : .flowing)
    panel.apply(liquid.follow(switcher.selection, at: now))                // first call: settled, no tracks
    self.liquid = liquid
    laidOutRow = switcher.row
}
```

`look` is a new `SwitcherPresenter.init` parameter, `liquidLook: @escaping () -> LiquidLook = { .shipped }`, read once per swipe. `SettingsShell` keeps calling `SwitcherPresenter(launcher:)` for now; a later slice threads the closure through.

## Rules that apply

- `docs/architecture.md`, Shape: "`LauncherCore` (domain types, pure policy, ports, the models; imports Foundation and Observation only)". No AppKit, QuartzCore or CoreGraphics types in Core; `LiquidTime` is a plain `Double`.
- `docs/architecture.md`, Shape: "Framework and wire types never cross a port … `NSImage` stay inside adapters and views." And: "Policy lives in pure functions and value types; the shell stays thin." The panel and presenter decide nothing; every number comes from the layout or the frame.
- `docs/architecture.md`, Concurrency: "Animation is Core Animation keyframes, which the render server plays. … No code of ours runs per display frame, and display links are banned along with timers. Code may run per input event while the effect it serves is on screen: the app switcher's liquid … on trackpad frames." No timers, display links or run-loop polling; `SourcePolicyTests` enforces it.
- `docs/architecture.md`, Concurrency: "`LauncherCore` and `LauncherPlatform` are nonisolated by default … `LauncherUI` and the app target use main-actor default isolation." `Liquid` and the value types are `Sendable` values, nonisolated.
- `docs/architecture.md`, Language: "Tests use Swift Testing."
- `docs/domain-model.md`, Switcher (the words to use in names, comments and tests): "one Liquid Glass shape centred on the pointer's display, with no panel around it … The shape is a band that runs under the icons and pools into a bead around each one, narrowing into a neck between neighbours; around the selected icon it swells into a bigger drop, and the selected icon is drawn slightly larger, inside the swell. … Icons are 80 pt, their centres 100 pt apart; each bead is as wide as its icon, and the swell rises 12 pt beyond the beads on every side. When that row would not fit the display, the icons and every dimension of the shape shrink by one factor … With the system's Reduce motion setting on, the shape still shows, but the swell jumps straight to the selected icon."
- R17 hand check, which the code must make true: "A grep of the switcher's LauncherUI files finds no numeric look literal other than 0, 1 and 2." Every look number lives in `LiquidLook` or `SwitcherRowLayout`.

- **Delivery.** Every value passes through a delivery stage. It can withhold values (as `Observations` coalescing does), feed a value twice, delay a value's time by a seeded 0 to 4 ms, or stamp two values 0.5 ms apart. Build the stage now with pass-through as the default; later rows use the rest.
- **The record.** It records every call: its time, the selection fed, the `LiquidFrame`, and a copy of the `Liquid` after it. It also keeps the layout.
- **`run.played(at:)`** rebuilds what the render server shows from the staged frames alone, by Core Animation's rules, not `Liquid`'s formulas. This slice needs only the rests and the icon: the swell is its last staged rest at or before the instant; beads are the layout's beads; the band never moves. - **Terms.** An icon's **body** is an `iconBody × scale` square on its centre; the selected icon's body is `selectedIconBody`. "Inside" is checked by rects.

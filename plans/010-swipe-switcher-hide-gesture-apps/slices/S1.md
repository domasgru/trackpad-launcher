# S1: The switcher leaves out the apps that have a gesture

**What to build:** From the user's side: when a swipe begins, the switcher's row no longer shows any running app that one of the five gestures is assigned to, the frontmost app excepted, and the freed slots go to the next most recently used running apps without a gesture, so the row still holds up to 10 icons; a swipe with only assigned apps behind the frontmost app, or with Trackpad Launcher active and every running app assigned, shows nothing and still blocks clicks and scrolling until the fingers lift; an assignment set or cleared in the launcher window counts from the very next swipe; an assignment whose app was moved to the Trash still hides it; the swap still reaches an assigned app; the window gains no control. Underneath: the Switcher's initializer takes the set of assigned bundle identifiers and leaves those apps out of the others; the model derives that set from its settings on the swipe's `.began` and passes it; the existing Switcher tests pass an empty set; the two documents.

## Goal

Trackpad Launcher stops being a menu bar app. It has no status item. A new process-level model, `Lifecycle`, decides what a start, a reopen and a quit do: opened by hand it runs gestures with its settings window open (or brings the running copy's window to the front); started at login it runs gestures silently. The settings window is an ordinary titled window centred on the pointer's display; the app is in the Dock and ⌘-Tab exactly while it is open. The close button, ⌘W, Escape, the app menu's *Close Settings* (⌘Q) and the Dock's Quit only close the window. A logout ends the app; the red *Quit Trackpad Launcher* button at the end of the window ends it. A first opening by hand on a Mac without settings registers starting at login and asks for Accessibility.

Not in this slice: other running copies (S3), `Placement`/`CodeSignature` and Quit turning login off (S4), the move dialog (S5/S6), gesture effects no longer closing the window (S2 — they may still close it here), the frontmost rule (S2).

## Requirements

- **R1.** Trackpad Launcher MUST NOT show an icon in the menu bar, in any state.
- **R2 (in part).** Opening the copy in /Applications while Trackpad Launcher runs MUST NOT start a second one that recognises gestures. It MUST open the running one's settings window instead. Scenarios: opened from Spotlight while running in the background → the settings window opens in front with the keyboard focus, the Dock shows one icon; opened while the window is behind other windows → the same window comes to the front, no second window; opened while minimised → restored and in front.
- **R4.** Opening the app by hand from /Applications while it is not running MUST start Trackpad Launcher and open its settings window (after Quit; after a crash).
- **R5.** The first run is the first run on a Mac that holds no saved Trackpad Launcher settings. The first run from /Applications MUST make Trackpad Launcher start at every login, ask for the Accessibility permission when it is missing, and open the settings window. Gestures MUST work from that moment on, with no further step. Later runs MUST NOT ask for the permission (they show the Accessibility hint instead).
- **R6.** Trackpad Launcher MUST appear in the Dock and in ⌘-Tab while its settings window is open, minimised included. It MUST leave both when the window closes. Gestures MUST keep working.
- **R7.** The settings window MUST be a normal macOS window with the close and minimise buttons. It MUST open centred on the display under the pointer, in front, with the keyboard focus, every time it opens. It MUST stay open when the user clicks elsewhere or switches to another app.
- **R8.** The app menu's quit item MUST NOT read *Quit Trackpad Launcher*. It MUST read *Close Settings*, with ⌘Q, and close the settings window. Each of these MUST close the settings window and keep Trackpad Launcher running: the close button; ⌘W; Escape, when no menu or chooser is open (when one is open, Escape closes that first); ⌘Q, or *Close Settings*; *Quit* in the Dock icon's menu. Logging out, restarting and shutting down MUST still end Trackpad Launcher without the user being asked. Scenario: closing the window while the *Other…* chooser is open via the Dock's Quit → the chooser and the window close, the gesture keeps its app.
- **R9.** While starting at login is on, Trackpad Launcher MUST start at every login with no window, no Dock icon, no dialog and no permission prompt. This holds when the settings window was open at logout, and when the Accessibility permission is missing. Gestures MUST work from the moment it starts.
- **R10.** The settings window MUST end with a *Quit Trackpad Launcher* button, below every other setting, notice and hint, aligned right. It MUST be a Liquid Glass capsule tinted solid red, with white text, at the system's regular button size.
- **R11 (in part).** Pressing *Quit Trackpad Launcher* MUST stop Trackpad Launcher at once, with no confirmation: the window and the Dock icon disappear and no gesture is recognised. (Turning starting at login off is S4.)
- **R14.** Trackpad Launcher MUST NOT relaunch by itself after it crashes or is force-quit. It MUST start again at the next login, while starting at login is on, or when the user opens it.

## Design

### Shape (from the plan)

One process-level owner, `Lifecycle` (LauncherCore, `@MainActor @Observable`), decides; the app delegate parses AppKit signals into values and forwards them, and builds the gesture model (`Launcher`) and its window only when `Lifecycle` asks for them (via a `makeResident` closure). The settings window talks to `Launcher` as today, plus a Quit closure into `Lifecycle`. A process is in exactly one private `Lifecycle.Stage`, the only record of what the process is doing; `launcher` is derived from it. Facts are values parsed once at the AppKit boundary (`Opening`, `Launch`, `QuitRequest`). The settings window state is `Launcher.Window { closed, open(request:) }`; every opening by hand increments the request, so reopening an open or minimised window is still a state change the shell renders.

```swift
// Lifecycle.swift: one process, from start to exit. Imports Foundation and Observation only.

/// How macOS started this process, or opened it again. Parsed from the open/reopen Apple event by `ThisCopy`.
public enum Opening: Equatable, Sendable {
    /// As a login item: the open event carries the login-item marker. Silent: no window, dialog or prompt.
    /// (Core doc comments never spell a confined API name: the source scan reads comments.)
    case atLogin
    /// Finder, Spotlight, Launchpad, the Dock, Xcode, or a move finishing: every opening that is not at login.
    case byHand
}

/// What one opening of this process leads to: the whole table, pure. (S1 subset: S3 adds `end` and an
/// `olderCopyRuns:` parameter, S5 adds `askToMove` and a `placement:` parameter.)
public enum Route: Equatable, Sendable {
    case runSilently, runWithWindow
    public init(_ opening: Opening)   // .atLogin → .runSilently; .byHand → .runWithWindow
}

/// One process start.
public struct Launch: Equatable, Sendable {
    public var opening: Opening
    public init(opening: Opening)     // S6 adds `diskImageToEject: DiskImage? = nil`
}

/// The quit being handled in `applicationShouldTerminate`, as `QuitSignals` classifies it.
public enum QuitRequest: Equatable, Sendable {
    /// Logout, restart, shutdown: the event carried a quit reason, came from loginwindow, or arrived after power-off
    /// was announced.
    case system
    /// The Dock's Quit, AppleScript, Activity Monitor's Quit, another app.
    case other
}

/// The running Trackpad Launcher processes. Real: SystemRunningCopies. Test: InMemoryRunningCopies.
/// (S1 subset: S3 adds `others()` and `stop(_:then:)`.)
@MainActor public protocol RunningCopies: AnyObject {
    /// AppKit's terminate for this process; `Lifecycle.shouldEnd` has already agreed (stage `.ending`).
    func endThisCopy()
}

/// This app's login item, as the main app's Open at Login entry. Real: SystemLoginItem. Test: InMemoryLoginItem.
/// (S1 subset: S4 adds `isOn` and `unregister()`.)
@MainActor public protocol LoginItem: AnyObject {
    /// True when registered afterwards, already-registered included; false when macOS refused (the user turned it off
    /// in Login Items, an unsigned build).
    @discardableResult func register() -> Bool
}

/// Starting at login: the one owner of "Trackpad Launcher turns back on only what it turned off itself".
/// (S1 subset: S4 adds `defaults:` and `placement:` to init, its own defaults key, `suspend()` and `resume()`.)
@MainActor public final class StartAtLogin {
    public init(item: any LoginItem)
    /// The first run: turn it on. A user's earlier off stands: macOS refuses.
    public func enrol()   // item.register()
}

/// What this process does as it starts, is opened again and is asked to quit.
@MainActor @Observable
public final class Lifecycle {
    /// Every legal situation of the process, and nothing else. Written only by the intents.
    private enum Stage {
        case idle                 // before `launched`
        case resident(Launcher)   // gestures run
        case ending               // `endThisCopy` called; every quit passes
    }
    private var stage: Stage = .idle

    /// Derived: the gesture model once it runs; nil before.
    public var launcher: Launcher? { get }

    public init(copies: any RunningCopies, makeResident: @escaping @MainActor () -> Launcher)

    /// Once, from applicationDidFinishLaunching. A second call does nothing.
    public func launched(_ launch: Launch) {
        // guard case .idle = stage
        // let launcher = makeResident(); launcher.start(); stage = .resident(launcher)
        // if Route(launch.opening) == .runWithWindow { launcher.openedByHand() }
    }

    /// From applicationShouldHandleReopen.
    public func openedAgain(_ opening: Opening) {
        // (.resident(let launcher), .runWithWindow) → launcher.openedByHand()   // R2: front, restored, focused
        // default: nothing   // a login start reaching the running copy; the process leaving
    }

    /// From applicationShouldTerminate.
    public func shouldEnd(_ request: QuitRequest) -> Bool {
        // .ending: true
        // .resident(let launcher):
        //     // Every ordinary way to quit exists only while the window is open (R8): close it, keep running.
        //     // With it closed, a quit is the system's or a script's: end, never hold up a logout.
        //     if request == .other && launcher.isWindowOpen { launcher.closeWindow(); return false } else { return true }
        // .idle: true
    }

    /// The Quit Trackpad Launcher button (R11). S4 adds `startAtLogin.suspend()` before `end()`.
    public func quit() { /* guard launcher != nil; end() */ }

    private func end() { /* stage = .ending; copies.endThisCopy() */ }
}
```

Order matters in `end()`: set `.ending` before calling `endThisCopy()`, because `endThisCopy` (NSApp.terminate) re-enters `shouldEnd(.other)` synchronously, and it must answer yes even with the window open (T6).

### App target: `TrackpadLauncher/TrackpadLauncherApp.swift`

The composition root and the only `NSApplicationDelegate`:

```swift
@main enum TrackpadLauncherApp {
    static func main() {
        let delegate = AppDelegate()
        NSApplication.shared.delegate = delegate
        withExtendedLifetime(delegate) { NSApplication.shared.run() }
    }
}

final class AppDelegate: NSObject, NSApplicationDelegate {
    private var lifecycle: Lifecycle!
    private var shell: SettingsShell?
    private let quitSignals = QuitSignals()
    private var event: NSAppleEventDescriptor? { NSAppleEventManager.shared().currentAppleEvent }

    func applicationWillFinishLaunching(_: Notification) {
        NSApp.disableRelaunchOnLogin()                     // R9: only the login item starts it at login
        let startAtLogin = StartAtLogin(item: SystemLoginItem())
        lifecycle = Lifecycle(copies: SystemRunningCopies(),
                              makeResident: { [unowned self] in makeResident(startAtLogin) })
    }
    func applicationDidFinishLaunching(_: Notification) {           // the open event exists only from here
        lifecycle.launched(ThisCopy.launch(event: event, arguments: CommandLine.arguments))
    }
    func applicationShouldHandleReopen(_: NSApplication, hasVisibleWindows _: Bool) -> Bool {
        lifecycle.openedAgain(ThisCopy.opening(of: event)); return false
    }
    func applicationShouldTerminate(_: NSApplication) -> NSApplication.TerminateReply {
        lifecycle.shouldEnd(quitSignals.request(for: event)) ? .terminateNow : .terminateCancel
    }

    /// The gesture model and the window that renders it, built together, only for a copy that runs gestures.
    private func makeResident(_ startAtLogin: StartAtLogin) -> Launcher {
        let catalog = AppCatalog.system
        let launcher = Launcher(
            hardware: MultitouchTrackpads(), preferences: SystemTrackpadPreferences(), permissions: SystemPermissions(),
            system: WorkspaceActions(), catalog: catalog, scanner: SystemAppScanner(catalog: catalog),
            store: SettingsStore(defaults: .standard), startAtLogin: startAtLogin)
        shell = SettingsShell(launcher: launcher, quit: { [unowned self] in lifecycle.quit() })
        return launcher
    }
}
```

- `makeResident` builds the shell before `Lifecycle` calls `launcher.start()`, so the first icon pass runs before gestures run.
- DEBUG: the animation tuner (`WorkspaceActions.showAnimationTuner()`) opens with the first opening by hand (not at a login start) and never drives the Dock (no `setActivationPolicy` outside `SettingsShell`). Keep it `#if DEBUG`.

### Tests: `LifecycleWorld` (new, `LauncherKit/Tests/LauncherCoreTests/LifecycleWorld.swift`)

The high test seam: a real `Lifecycle` building a real `Launcher` over today's in-memory adapters. It sits beside `World` and models one Mac:

- **What outlives a process:** one throwaway defaults suite holding the `settings` record (build it under a temp root the way `World` does, and remove it in `deinit`), plus `InMemoryLoginItem`, `InMemoryPermissions` (grants and asks) and the fixture apps.
- **`InMemoryLoginItem`** (new): `isOn` (a settable var standing for the user's Login Items choice; S4 makes it part of the port), and an ordered `calls` log of `register` calls. `register()` turns it on and returns true. (S4 adds the two readings of a user's off.)
- **A process:** `start(...)`/`launch(...)` builds a `Lifecycle` with its own `InMemoryRunningCopies`; its `makeResident` builds a real `Launcher` over fresh in-memory sensing adapters (sharing the Mac's suite, login item and permissions) and counts `residentsBuilt`. `login()` is macOS at login: it starts a process at login only while the login item is on. A process dropped without an intent has crashed or been force-quit.
- **`InMemoryRunningCopies`** (new): `endThisCopy()` does what `NSApp.terminate` does: it asks the lifecycle `shouldEnd(.other)` and records `hasEnded` only on yes.
- **History:** record the window state after each intent, so tests assert sequences like `closed, open(1), open(2), open(3), closed, open(4)`.
- Hooks that read the store at the moment of an effect (e.g. "registered and asked while `store.load()` is still nil") follow `PersistenceTests`/`AccessibilityTests`.
- No clock. No timers.

Existing `World`: its `Launcher` init gains `startAtLogin:` (over an `InMemoryLoginItem`). Tests that relied on `start()`'s first-launch branch call `openedByHand()` after `start()`. `World.relaunch()` must say how the app was started where it matters (a relaunch that opened no window is now a login start; one opened by hand opens the window). ## Rules that apply

- `docs/architecture.md` § Shape: "`LauncherCore` (domain types, pure policy, ports, the models; imports Foundation and Observation only)". `Lifecycle.swift` must not import AppKit or ServiceManagement. "Framework and wire types never cross a port: … `NSRunningApplication`, `NSImage` stay inside adapters and views. External data is parsed into domain types at the adapter." `NSAppleEventDescriptor` stays in `ThisCopy`/`QuitSignals`/the app target.
- § Shape: "Every port has exactly two adapters: the real one in `LauncherPlatform` and an in-memory one in the tests." `LoginItem` → `SystemLoginItem` + `InMemoryLoginItem`; `RunningCopies` → `SystemRunningCopies` + `InMemoryRunningCopies`.
- § Shape: "the AppKit/SwiftUI shell renders the models' state and forwards user intents. Policy lives in pure functions and value types; the shell stays thin." No lifecycle policy in `AppDelegate` or `SettingsShell`.
- § Concurrency: "`LauncherCore` and `LauncherPlatform` are nonisolated by default; the model, the ports and the public surface of every real adapter are `@MainActor`. `LauncherUI` and the app target use main-actor default isolation."
- § Concurrency: "No timers, no polling, no background loops: every input is a push." `Timer`, `asyncAfter`, `Task.sleep` are banned by the source scan.
- § Concurrency: "The first scan and the first icon pass are the exception: they run, and are waited for, before gestures run and before the settings window can show."
- § Privacy: "no logging of any kind"; "A source-scan test in `LauncherCoreTests` fails the build on any banned API; add to its list rather than adding prose." "The NSEvent monitors [are confined] to the launch bounce's overlay."
- Domain model, *Settings window*: "The window that opens when the user opens Trackpad Launcher by hand: an ordinary macOS window with the close and minimise buttons, centred on the display under the pointer, in front and with the keyboard focus, every time it opens. … and last, below everything and aligned right, the *Quit Trackpad Launcher* button. … It closes only by its close button, ⌘W, Escape (when no menu or chooser is open), *Close Settings* (⌘Q) in the app menu and *Quit* in the Dock icon's menu, and gestures keep working after it closes. Clicking another app, … *Other…* (whose file chooser is a sheet on the window) and the System Settings buttons all leave it open."
- Domain model, *Login start*: "A login start is silent wherever the copy lies: no window, no Dock icon, no dialog and no permission prompt, and gestures work from that moment. It never does the first run's work. A window that was open at logout does not come back."
- Domain model, *First run*: "The first opening by hand on a Mac that holds no saved Trackpad Launcher settings. It turns starting at login on …, asks for the Accessibility permission when it is missing, and opens the settings window. Later runs never ask for the permission; the Accessibility hint shows instead."
- Domain model, *Quit Trackpad Launcher*: "the only control of the app's own that stops it: at once, with no confirmation … Every other way to quit, *Close Settings* (⌘Q) in the app menu and *Quit* in the Dock icon's menu, only closes the settings window. Logging out, restarting and shutting down end Trackpad Launcher without asking."
- Use the glossary's words in code and comments: *settings window* (never "launcher window"/"menu window"/"panel" for it), *opened by hand*, *login start*, *first run*, *starting at login*.
- The model never holds a `terminate` closure: ending this process is the `RunningCopies.endThisCopy()` port command.

# Check: two toolchain claims from the candidates

Gathered after fan-out. Probe: `checks/swift6-probe/main.swift`; strict-mode build error in `build-strict-error.txt`; Swift 5 build log in `build-swift5.txt`; output in `output.txt`. Xcode 26.6, SDK 26.5, 2026-10-09.

- **probed:** `kAXTrustedCheckOptionPrompt` is declared `extern CFStringRef` (not const) in `HIServices/AXUIElement.h:66`, so Swift imports it as a global `var` of type `Unmanaged<CFString>`. Under `-swift-version 6 -strict-concurrency=complete` any reference to it, even from a `@MainActor` function or through `nonisolated(unsafe) let`, fails with "reference to var 'kAXTrustedCheckOptionPrompt' is not concurrency-safe because it involves shared mutable state". Its runtime value (read in Swift 5 mode) is the string `"AXTrustedCheckOptionPrompt"`. Conclusion: candidate-1's note is right; the permission adapter passes `["AXTrustedCheckOptionPrompt": true] as CFDictionary` to `AXIsProcessTrustedWithOptions`, and a one-line comment names the header constant it stands for.
- **probed:** `CGEventType(rawValue: 34)` (NSEventTypePressure, which has no public `CGEventType` case) returns a value whose `rawValue` is 34; shifting it into a `CGEventMask` sets bit 34 (`0x400000006` with bits 1 and 2); `CGEvent.type` accepts it as a rewrite target. Conclusion: the tap's type table can list the pressure type beside the public cases and the mask builder needs no special case. Whether the WindowServer delivers pressure events to a session tap with that bit set is still the manual Force Click check.
